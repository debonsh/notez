Lesson · BT203 Unit 2 — Measurement & Production

Errors in Measurement — Systematic, Random, and How Each Is Killed

Every measurement is wrong. The only question is how it is wrong, because that decides whether averaging fixes it or makes it worse. RGPV asks “What is error? Types of errors in measurement” as a part-question more than almost anything else in this unit, and it is the one topic where the whole answer is a definition plus a two-way classification. Learn the two classes and their elimination methods and this question is finished.

The one-sentence statement

Measurement error is the difference between the measured value and the true
value of the quantity being measured. It is classified as systematic
(constant bias, removed only by calibration or correction) and random
(unpredictable scatter, reduced only by averaging repeated readings); a
third class, gross error, comes from blunders and is removed by care.

Then the framing sentence that makes the rest of the page logical: “The class of error decides its cure — averaging destroys a random error and does nothing whatever to a systematic one.”

True, apparent and standard value

TermMeaningReachable?
True valueThe exact value of the quantity — unknowable in practiceNo, never measured, only approached
Apparent valueThe value indicated by the instrument, which is what you actually readYes, it is the reading
Standard valueThe value agreed between a national standard and a national prototype, used as the referenceYes, through calibration chains

Since the true value is unreachable, error is always defined against a substitute for it — usually the standard value or the mean of many readings. That is why the choice of reference is not pedantry: it decides the number you write.

The three ways of expressing an error

FormFormulaUse it when
Absolute errore = measured value − true valueReporting the error itself
Relative errorer = absolute error / true valueComparing errors of different quantities — it is dimensionless, so it is the only form that can be compared
Percentage errore% = (absolute error / true value) × 100Every exam answer. This is the form RGPV expects by default

The distinction that carries the mark

Write both of these sentences and the classification is complete: “A systematic error is a constant bias that cannot be removed by averaging; it is removed only by calibration or by applying a known correction. A random error is an unpredictable scatter that is reduced only by averaging repeated readings.”

The reason it is the mark is that most candidates can name the two types but only half can state why averaging does not cure a systematic error. Add that clause.

Gross errors and instrumental errors

RGPV's own wider treatment names a third practical class alongside the two above.

  • Gross error — a blunder, not a bias: misreading a scale, a wrong zero, a transcription slip, the observer reading the wrong end of the instrument. The value is wildly out of line. It is removed by care, and it is detected by repeating the measurement — the outlier is obvious.
  • Instrumental error — error built into the instrument itself: a worn vernier, a zero error, a miscalibrated micrometer. It is systematic, because the instrument is consistently wrong in one direction. Hence the closing move: correct the instrument, or apply a correction from calibration.
  • Environmental error — temperature, humidity, magnetic or electric fields affecting the reading. Also systematic, and removed by controlling the environment.

Precision is not accuracy. A badly calibrated micrometer can be perfectly precise — every reading 0.02 mm too high — and still be systematically wrong. That is the cleanest illustration of the whole page: a cluster of tight readings proves precision, and only comparison against a standard proves accuracy. If one sentence is needed to separate the two words, this is it.

Given:  measured value and true (or standard) value, with units

Solved A — percentage error of a single reading

A measured length is 25.36 mm and the true length is 25.34 mm. Find the absolute and percentage error.

Given: Vm = 25.36 mm, Vt = 25.34 mm. Find: absolute and percentage error. Formula: e = Vm − Vt; e% = (e / Vt) × 100. Solve:

e   = 25.36 - 25.34 = +0.02 mm
e%  = (0.02 / 25.34) x 100 = 0.0789%

Answer: absolute error +0.02 mm, percentage error 0.079% (about 0.08%).

Check: the sign of e is positive because the measured value is the larger of the two, and that must be stated. Independent second check: the ratio 0.02 / 25.34 is about 7.9 x 10-4, which is under a thousandth of the measurement — entirely consistent with an instrument resolving 0.01 mm. Had the answer come out around 0.08 the decimal has slipped by a place.

Solved B — reducing a systematic error by correction, not by averaging

A vernier reads 45.32 mm for a standard length known to be 45.50 mm. Find the correction to be applied, and state whether averaging ten such readings would remove it.

The instrument has a fixed zero error, so the bias is identical on every reading.

Given: reading = 45.32 mm, standard = 45.50 mm. Find: the correction, and the effect of averaging. Formula: error e = reading − standard; correction = −e. Solve:

e = 45.32 - 45.50 = -0.18 mm
correction = -e = +0.18 mm
corrected reading = 45.32 + 0.18 = 45.50 mm

ten averaged readings still read 45.32 mm each
average = 45.32 mm  ->  still 0.18 mm wrong

Answer: apply a correction of +0.18 mm; averaging will not help, because every reading carries the same bias.

Check: adding the correction back returns exactly the standard, 45.50 mm, so the sign of the correction is right. The averaging line is the conceptual check: ten readings each scattered around 45.32 still average to 45.32, which is exactly why a systematic error survives averaging and a random error does not.

Solved C — random error against systematic error, from a set of readings

Repeated measurements of a length give 20.11, 20.09, 20.13, 20.10 and 20.12 mm, and the standard value is 20.00 mm. State which part of the total error is random, which is systematic, and what averaging achieves.

Given: five readings in mm; standard = 20.00 mm. Find: the two error components and the effect of averaging. Formula: mean = sum / n; error relative to the standard = mean − standard. Solve:

mean = (20.11 + 20.09 + 20.13 + 20.10 + 20.12) / 5
     = 100.55 / 5 = 20.11 mm

scatter about the mean: +0.00, -0.02, +0.02, -0.01, +0.01
mean error vs standard = 20.11 - 20.00 = +0.11 mm
percentage error       = (0.11 / 20.00) x 100 = 0.55%

Answer: the random error is the scatter of ±0.02 mm about the mean, and it is what averaging shrinks. The systematic error is the +0.11 mm offset of the whole cluster from the standard — averaging leaves it completely untouched, so the instrument still reads 0.55% high.

Check: averaging five readings gave 20.11 mm and the un-averaged first reading was also 20.11 mm, which shows the averaging barely moved the centre while it removed the scatter — exactly the expected behaviour. Second check: the readings are all in 20.09–20.13, a spread of 0.04 mm, which is about four least counts of a 0.01 mm micrometer — a plausible scatter. The residual +0.11 mm is roughly eleven least counts, far too large to be scatter, which is why it must be read as a bias to be corrected.

Numeral traps in this topic
  • Percentage error is over the true value, not over the measured value. Using Vm in the denominator gives a slightly different number and is the commonest slip in the whole topic.
  • Keep the sign of e. −0.18 mm and +0.18 mm are different claims. If the question does not ask for a sign, still write it.
  • The correction has the opposite sign to the error. The instrument reads low by 0.18 mm, so you add 0.18 mm. Adding the error instead doubles it.
  • Percentage error of a systematic error does not shrink with n. Averaging is only a cure for random error; do not divide a bias by the number of readings.
  • Do not mix relative error with percentage error. Relative error is a decimal (0.00079); percentage error is that same number × 100 (0.079). Writing the decimal where a percentage is asked loses the mark.
  • No unit on a relative error. It is dimensionless — writing “0.079%” where “0.079%” was asked is fine, but writing “0.00079 mm” is wrong.
Special lines for extra marks
  • Opening line — “The error of a measurement is the difference between the measured value and the true value, and it is of two types — systematic and random.”
  • Distinguishing line — “A systematic error is a constant bias that averaging cannot remove; a random error is an unpredictable scatter that averaging does remove.”
  • Elimination line — “Systematic error is eliminated by calibration or by applying a known correction; random error is reduced by averaging repeated readings, by improving the least count, and by controlling the environment.”
  • Accuracy line — “Accuracy is closeness to the true value and precision is closeness of repeated readings to one another, so a set of tight readings proves only precision.”
  • Closing line — “Hence an instrument may be highly precise and still systematically in error, and it is only comparison against a standard that establishes accuracy.”
Exam tips
  • Statement first — one line of definition before any table or list
  • Two-column table beats prose — systematic against random, one row per property, is the shape the marks are scored against
  • Always pair a type with its cure — a classification without elimination methods scores half
  • Underline the keyword — constant bias, scatter, calibration, averaging
  • Attempt this early — it is pure recall with no calculation, so it is one of the fastest marks on the paper
  • Never leave blank — a definition, two types and two cures clears 4 of 7

Cheat-Sheet · BT203 Unit 2 Topic 01

Errors in Measurement — Full Revision

Statement to write verbatim

The error of a measurement is the difference between the measured value
and the true value of the quantity. It is of two types:

  SYSTEMATIC - a constant bias, same sign and nearly same magnitude on
               every reading. NOT removed by averaging. Removed by
               calibration, correction, zeroing, or a changed method.

  RANDOM     - an unpredictable scatter, sign and size changing at
               random. Reduced only by averaging repeated readings,
               a finer least count, or environmental control.

A third class, GROSS ERROR, is a blunder - misreading, wrong zero,
transcription slip - detected by repetition and removed by care.

Derivation in four steps

1. Define        -> error = measured value - true value
2. Classify      -> systematic (constant bias) or random (scatter)
3. Give the cure -> calibrate/correct for systematic,
                    average for random
4. Close the loop-> precision is tightness, accuracy is closeness to
                    the standard; a tight cluster proves only precision

Reference table

PropertySystematicRandom
NatureConstant biasUnpredictable scatter
Sign and sizeSame sign, nearly same sizeChange at random
Typical causeZero error, wrong calibration, wrong method, environment, observer biasRandom fluctuation in the process and surroundings
Effect of averagingNot reducedReduced by 1/sqrt(n)
EliminationCalibration, correction, zeroing, better methodAveraging, smaller least count, damping the environment
Detected byComparison against a standardRepetition — the scatter is visible

Definitions to reproduce

  • Error — the difference between the measured value and the true value of the quantity being measured.
  • Absolute error — measured value minus true value, in the units of the quantity.
  • Relative error — absolute error divided by the true value; dimensionless, and therefore the only form in which two errors can be compared.
  • Percentage error — relative error multiplied by 100; the form every exam answer is expected in.
  • Systematic error — a constant error with a fixed sign and magnitude, caused by calibration, method or environment; not removable by averaging.
  • Random error — an error varying unpredictably in sign and size; reducible only by averaging repeated readings.
  • Gross error — a blunder in reading or recording; the outlier is identifiable by repetition.
  • Accuracy — closeness of a reading to the true value.
  • Precision — closeness of repeated readings to one another.
  • Sensitivity — the instrument response per unit change of input, that is, the smallest change it can resolve.

Checklist before you call the topic done

  • [ ] Can define error against the true value in one sentence
  • [ ] Can name the two classes and give one cause of each
  • [ ] Can state why averaging fails on a systematic error
  • [ ] Can give at least two elimination methods for each class
  • [ ] Can distinguish accuracy from precision without hesitating
  • [ ] Can write all three error forms and say which one compares two errors
  • [ ] Can solve a percentage-error numeral with the true value in the denominator
  • [ ] Can state the sign of the correction when an instrument reads low

Numeral shortcut

Three moves only. Subtract to get the absolute error, keeping the sign. Divide by the true value to get the relative error. Multiply by 100 for the percentage. Finish by asking whether the error is systematic or random — if the readings all sit on one side of the standard, it is a bias and averaging will not touch it.

Model answer · 5 marks

How are systematic and random errors eliminated? Explain the methods.

Two lists, but each method must be attached to the class it actually cures. An unlabelled list of methods scores less than a short correctly paired one.

              |                                  |

   |        value)        |         readings       |          |
   |          |           |            |          |          |

 BIAS       known        a           the         finer     external
            BIAS        METHOD       SCATTER    changes   disturbances
                              |
                       affects both

Systematic errors are eliminated by correcting the instrument itself or its record of what it reads. The methods are:

  • Calibration — comparing the instrument against a standard and adjusting it, which removes a zero error and a scale error.
  • Applying a known correction — where recalibration is impractical, the previously determined error is applied to every reading with the opposite sign.
  • Zeroing the instrument — removing the zero or index error before use.
  • Changing the method — choosing a procedure that avoids the bias, such as using the two-peg method to eliminate local attraction in levelling.

Random errors are reduced rather than eliminated, because they have no fixed sign to cancel:

  • Averaging many readings — the standard remedy; the scatter falls as 1/sqrt(n).
  • A smaller least count — a finer resolution reduces the magnitude of each fluctuation.
  • Controlling the environment — damping vibration and stabilising temperature removes the external part of the scatter.

Exam close: "A systematic error is eliminated and a random error is only reduced, because elimination requires a known sign to cancel and a random error has no consistent sign."

Differentiate between accuracy and precision. Is a precise instrument necessarily accurate?

Accuracy is the closeness of a measured value to the true value of the quantity. Precision is the closeness of repeated readings to one another, however far they all sit from the true value. Sensitivity is distinct from both: it is the response of the instrument per unit change of input, that is, the smallest change it can detect.

A precise instrument is not necessarily accurate. A micrometer whose zero has drifted reads 0.02 mm high on every single reading. Its readings agree with each other perfectly, so it is highly precise, yet every value it reports is wrong by a fixed amount, so it is inaccurate. The group of readings is tight and displaced from the true value.

Exam close: "Precision is proved by the agreement of readings with one another, while accuracy is proved only by comparison with a standard — so an instrument may be precise and still systematically in error, and the cure for the second is calibration, not averaging."
