# Unit 1 — Calculus (BT102 Mathematics-I)

Hub: `index.html` — open in any browser, no server needed.

## Order (exam priority)

1. `01-rolles-theorem.html` — Rolle's Theorem. 3 conditions → f'(c)=0. Every session, 5-7 marks.
2. `02-lagranges-mvt.html` — Lagrange's MVT. Tangent ∥ secant. Feb-Apr cycles, 5-7 marks.
3. `03-taylors-maclaurins.html` — Taylor / Maclaurin expansions. Jun & Dec, 7-10 marks.
4. `04-maxima-minima.html` — Maxima/Minima two variables, D=rt-s². Most sessions, 7-10 marks.

Hub extras: `index.html` (Progress + PYQ map), `formula-sheet.html` (printable). All 4 topics: quizzes fixed (feedback + guard), 1 SVG each.

Each file: Lesson tab + Cheat-Sheet tab + 5 interactive MCQs + 5 PYQ drills.

## How to use

- Study in order 01 → 04.
- Exam morning: open only Cheat-Sheet tabs.
- PYQ sources + videos: `index.html` → Resources tab.
