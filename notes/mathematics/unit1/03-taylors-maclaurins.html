Taylor's & Maclaurin's Series — Expand Any Function Into a Polynomial

You've mastered Rolle's and Lagrange's MVT. Now it's time to approximate ANY function as an infinite polynomial. Taylor's series is one of the most powerful tools in calculus — and a guaranteed 7-mark question in RGPV BT102. Maclaurin's is just Taylor's centered at zero. Let's crack it.

Taylor's Theorem (the statement)

If f(x) is differentiable n times in [a, a+h], then its Taylor series expansion about x = a is:

f(x) = f(a) + (x-a)f'(a) + (x-a)!/2! f"((a) + ... + (x-a)"/n! f(")(a) + Rn(x)

Where Rn(x) is the remainder (error) term:

Rn(x) = (x-a)(n+1) / (n+1)! · f(n+1)(ξ)  for some ξ between a and x
The one-second intuition Taylor's series approximates any smooth function near a point using just that point's derivatives. The more terms you add, the closer the polynomial hugs the actual function. It's like saying: "I can rebuild this curve if I know its slope, curvature, rate of change of curvature... all at one point."

Maclaurin's Series (special case: a = 0)

When a = 0, Taylor's becomes Maclaurin's — the most common form in exams:

f(x) = f(0) + x f'(0) + x²/2! f"(0) + x³/3! f"'(0) + ...

Example 1 — Expand ex up to x³ (Maclaurin)

Q: Expand f(x) = ex as Maclaurin's series up to x³.

StepWork
1f(x) = ex, f(0) = 1
2f'(x) = ex, f'(0) = 1
3f"(x) = ex, f"(0) = 1
4f"'(x) = ex, f"'(0) = 1
5ex = 1 + x + x²/2! + x³/3! + ...
  Maclaurin expansion of ex

  Terms:  1  +  x  +  x²/2  +  x³/6  +  x&sup4;/24  +  ...
          ↑     ↑      ↑       ↑
        f(0)    f'(0)x  f"(0)x²/2  f"'(0)x³/6

  At x=1: e ≈ 1 + 1 + 0.5 + 0.1667 + 0.0417 = 2.7083...
  (actual e = 2.71828...)

  Error decreases as you add more terms → convergence

Example 2 — Taylor's series (sin x about π/6)

Q: Expand f(x) = sin x in powers of (x - π/6) up to 3 terms.

StepWork
1a = π/6, f(π/6) = sin(π/6) = 1/2
2f'(x) = cos x, f'(π/6) = √3/2
3f"(x) = -sin x, f"(π/6) = -1/2
4sin x ≈ 1/2 + (√3/2)(x-π/6) - (1/4)(x-π/6)² + ...

Exam tip — what RGPV asks Most common: "Expand ex/sin x/cos x up to x³ or x&sup4; using Maclaurin's." Less common but tested: Taylor's series about a non-zero point (like π/6 or 1). Always ask: "How many terms?" = up to which power of x. x³ means you need f"'(0).

Cheat-Sheet · BT102 Unit 1

Taylor's & Maclaurin's — Quick Reference

The formulas

Taylor (about x=a):
f(x) = f(a) + (x-a)f'(a) + (x-a)²/2! f"(a) + (x-a)³/3! f"'(a) + ...

Maclaurin (a=0):
f(x) = f(0) + xf'(0) + x²/2! f"(0) + x³/3! f"'(0) + ...

Standard Maclaurin expansions

Exam checklist

  • ☐ Maclaurin = Taylor at a = 0 — know when to use which
  • ☐ "Up to x³" = compute f(0), f'(0), f"(0), f"'(0)
  • ☐ Coefficient of xn is always f(n)(0) / n!
  • ☐ Alternating signs in sin, cos, ln(1+x)
  • ☐ All positive signs in ex
