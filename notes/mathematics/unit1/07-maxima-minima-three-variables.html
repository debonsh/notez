Lesson · BT102 Unit 1 — Calculus

Maxima & Minima of Three Variables & Lagrange's Multipliers

Syllabus items 8 and 9 of Module 1: "Maxima & Minima (two and three variables), Method of Lagranges Multipliers". Topic 04 handled two variables with the discriminant D = fxxfyy − fxy². This topic finishes the job: the three-variable test, and the constrained problem where the stationary-point method simply fails and a multiplier is needed instead.

Unconstrained stationary points in three variables

A stationary point of f(x, y, z) satisfies all THREE first
partials vanishing simultaneously:

  f_x = 0 ,   f_y = 0 ,   f_z = 0

That is three equations in three unknowns, so unlike the
two-variable case there is usually a FINITE, enumerable list
of candidate points rather than a curve of them.

The classification test (3x3 determinant)

Build the Hessian matrix of second partials at the point:

     | f_xx  f_xy  f_xz |
 H = | f_xy  f_yy  f_yz |
     | f_xz  f_yz  f_zz |

Let  D  = |H|   (the 3x3 determinant)

Then:
  D > 0 and all diagonal entries positive
        (in practice f_xx > 0)
                          -> LOCAL MINIMUM
  D > 0 and an ODD number of negative diagonal entries
        (in practice f_xx < 0)
                          -> LOCAL MAXIMUM
  D < 0                       -> SADDLE POINT
  D = 0                       -> inconclusive, go to
                                 higher order terms
The shortcut that saves the whole determinant A symmetric 3×3 matrix is positive definite (minimum) or negative definite (maximum) exactly when its leading principal minors are all positive (or an odd number of them negative). So in practice you only need the first two:
SymbolExpression
Δ1f_xx
Δ2f_xx f_yy − f_xy²
Δ3 = Dthe full 3×3 determinant
Δ1 > 0 and Δ2 > 0 and D > 0 → minimum. Δ1 < 0 and Δ2 > 0 and D > 0 → maximum. D < 0 → saddle. This is Sylvester's criterion, and writing the three quantities instead of expanding a 27-term determinant is the mark-winning move.

Where the plain method breaks — the constrained problem

Suppose you must maximise f(x, y) subject to g(x, y) = 0 — for example the largest volume of a box with 2x + 2y + 2z = 12 inches of sheet metal. Now f_x = 0 and f_y = 0 cannot both hold in general, because the constraint forbids moving freely. Setting the partials to zero is the wrong move. Lagrange's method replaces the constraint with a gradient alignment condition.

Method of Lagrange's multipliers (write verbatim)

To find the stationary values of f(x1, x2, ..., xn) subject to
the constraints  g(x1, ..., xn) = 0 ,  h(x1, ..., xn) = 0 :

Introduce one multiplier per constraint (say lambda, mu) and
consider the FUNCTION

      F = f - lambda g - mu h

Then form the n + m equations by differentiating F:

  F_x1 = 0 , F_x2 = 0 , ... , F_xn = 0
  together with the constraints themselves:
  g = 0 ,  h = 0

Solving this system gives the candidate points. Substitute each
into f, keep the largest and smallest values, and discard
infeasible points (negative sizes, outside the region).

For the common one-variable-independent case, constrained extremum
of f subject to g = 0 requires the two GRADIENTS to be parallel:

      grad f  =  lambda * grad g
      (f_x, f_y, f_z) = lambda (g_x, g_y, g_z)
The geometric reading — this is the whole idea in one line At a constrained extremum the surface z = f is just touching the cylinder (or surface) g = 0 without crossing it. Two surfaces that touch without crossing have the same tangent plane at the contact point, which is exactly what ∇f = λ∇g says. λ = 0 would mean ∇f = 0, i.e. an unconstrained stationary point that happens to satisfy the constraint — check those too, they are genuine candidates. 
  WHY  grad f = lambda * grad g
  ==========================================================
   Maximise  f  on the surface  g = 0
   (picture: a sphere resting on a plane, touching it)

        z
        ^
        |          surface  f  (a dome)
        |              .-''''-.
        |           .-'   .-----.   <- touching at P
        |        .-'    .'   /   '.     no crossing here
        |      .'     .'    /      '.
        |     /      /     /         \
        |    |      |     |   P       |
        +----|------|-----|-----------|----> y
             |      |    (0,0,c)       |
        ============================|==========  plane  g = 0

   At P the two surfaces SHARE a tangent plane, so their
   normals are parallel:

        grad f   =  lambda * grad g
           ^              ^
           |              |
           +-------->     +-------->
        both perpendicular to the shared tangent plane
  ==========================================================
   IF the surfaces CROSSED at P, the normals would not be
   parallel, and P would not be a constrained extremum.
   That crossing case is exactly what the unconstrained
   method f_x = f_y = 0 is for.
  ==========================================================

Worked Lagrange example — largest box from a sheet

Maximise  V = x y z   subject to  2x + 2y + 2z = 12
                        i.e.  g = x + y + z - 6 = 0

METHOD (one constraint, so one multiplier lambda)
  F = V - lambda (x + y + z - 6)
     = x y z - lambda x - lambda y - lambda z + 6 lambda

  F_x = y z - lambda          = 0
  F_y = x z - lambda          = 0
  F_z = x y - lambda          = 0
  g   = x + y + z - 6 = 0

FROM THE THREE EQUATIONS
  yz = xz   ->  z(y - x) = 0  ->  y = x   (z > 0 here)
  xz = xy   ->  x(z - y) = 0  ->  z = y   (x > 0 here)
  so  x = y = z.

INTO THE CONSTRAINT
  3x = 6   ->   x = y = z = 2

VOLUME
  V = 2 * 2 * 2 = 8 cubic inches   <- the CUBE

WHY IT IS A MAXIMUM
  lambda = yz = 4
  Boundary of the feasible triangle (say z = 0) gives V = 0,
  and the single interior critical point gives V = 8, so the
  interior value is the global maximum.
  Equivalently, x + y + z = 6 is fixed and xyz is largest when
  the three are equal (AM-GM: (x+y+z)/3 >= (xyz)^(1/3)).
Read the reasoning: equating yz = xz = xy and dividing by the positive sizes is the step that produces x = y = z. If a size is zero the box is degenerate and the volume is zero, so it cannot be the maximiser — that is why the "positive" qualifier in the algebra is legitimate, and saying so earns a mark.

Numericals in great depth

Both halves of this topic are mechanical once the method is fixed, so the marks live in the condition checks: never divide by a quantity that might be zero, and always compare against the boundary before declaring a global extremum.

Solved A — f = x² + y² + z² − 2x + 4y − 6z + 11, find and classify

Given:   f(x,y,z) = x^2 + y^2 + z^2 - 2x + 4y - 6z + 11
Find:    the stationary point, and classify it
Formula: W1  f_x = f_y = f_z = 0
         W2  Delta1, Delta2, Delta3

STEP 1  First partials
        f_x = 2x - 2      = 0   ->  x = 1
        f_y = 2y + 4      = 0   ->  y = -2
        f_z = 2z - 6      = 0   ->  z = 3
        One candidate point: (1, -2, 3)

STEP 2  Second partials at that point
        f_xx = 2     f_xy = 0     f_xz = 0
        f_yy = 2     f_yz = 0     f_zz = 2
        All second partials are constants, so the values are
        the same at every point.

STEP 3  Sylvester's criteria
        Delta1 = f_xx = 2                                  > 0
        Delta2 = f_xx f_yy - f_xy^2
               = (2)(2) - 0 = 4                             > 0
        Delta3 = |H|  with H = diag(2, 2, 2)
               = 2 * 2 * 2 = 8                              > 0
        All three positive -> the Hessian is positive definite
        -> LOCAL (indeed GLOBAL) MINIMUM

STEP 4  The minimum value
        f(1, -2, 3) = 1 + 4 + 9 - 2 - 8 - 18 + 11
                    = 14 - 28 + 11 = -3

CHECK:  Completing the square is the independent check and it
        is short:
          f = (x-1)^2 + (y+2)^2 + (z-3)^2 - 3
        Every square is >= 0, so f >= -3 with equality only
        at (1, -2, 3). That proves a GLOBAL minimum of -3, not
        merely a local one, and it confirms the sign of the
        minimum. If Delta1 had come out negative with Delta2
        and Delta3 positive, the same argument would prove a
        global maximum instead.
Check note — the trap in Solved A Expanding the 3×3 determinant term by term gives up to 27 products and a sign error is nearly certain. Note that here f_xy = f_xz = f_yz = 0, so H is diagonal and D = f_xx f_yy f_zz. Always check for that first: a separable f = g(x) + h(y) + k(z) has an off-diagonal-free Hessian and the determinant is a simple product. That one observation replaces the whole expansion.

Solved B — constrained: minimise f = x² + y² subject to x + y = 4

Given:   f(x, y) = x^2 + y^2 ,  constraint  x + y = 4
Find:    the constrained minimum, and verify it is a minimum
Formula: W3  F = f - lambda g ,  g = x + y - 4
         W4  grad f = lambda grad g

STEP 1  Build the augmented function
        F = x^2 + y^2 - lambda (x + y - 4)

STEP 2  Differentiate
        F_x = 2x - lambda        = 0
        F_y = 2y - lambda        = 0
        g   = x + y - 4 = 0

STEP 3  Solve
        From the first two:  2x = 2y  ->  x = y
        Into the constraint:  2x = 4   ->  x = y = 2
        lambda = 2x = 4

STEP 4  Evaluate
        f(2, 2) = 4 + 4 = 8   <- the MINIMUM

STEP 5  Prove it is a minimum, not a maximum
        Feasible set is the line x + y = 4, unbounded. Along
        it write y = 4 - x, so
          f(x) = x^2 + (4 - x)^2 = 2x^2 - 8x + 16
                            = 2(x - 2)^2 + 8
        The bracket is >= 0, so f >= 8 with equality only at
        x = 2. There is NO maximum: as x -> +infinity along
        the line, f -> +infinity. So (2,2) is the global
        MINIMUM and no maximum exists.

CHECK:  grad f = (2x, 2y) = (4, 4) at (2,2)
        grad g = (1, 1)
        lambda grad g = 4 * (1, 1) = (4, 4)   = grad f  PARALLEL
Read the reasoning: Step 5 is the part that earns the last mark. Lagrange's method returns candidate points; declaring one the global extremum requires either a completing-the-square bound or a boundary comparison. On an unbounded feasible set, a maximum may simply not exist — and saying that explicitly is a strong answer.

Solved C — Lagrange on a symmetric surface: largest box

Given:   maximise V = x y z  subject to  x + y + z = 6
         (from 2x + 2y + 2z = 12 of sheet metal)
Find:    the maximum volume, and justify that it is global
Formula: W3  F = V - lambda (x + y + z - 6)
         W5  yz = xz = xy  ->  x = y = z
         W6  AM-GM as the independent check

STEP 1  Augmented function
        F = x y z - lambda (x + y + z - 6)

STEP 2  Differentiate
        F_x = y z - lambda = 0
        F_y = x z - lambda = 0
        F_z = x y - lambda = 0
        g   = x + y + z - 6 = 0

STEP 3  Solve. All three of x, y, z are positive for a
        non-degenerate box, so dividing is legitimate.
        yz = xz   ->  z(y - x) = 0   ->  y = x
        xz = xy   ->  x(z - y) = 0   ->  z = y
        Hence x = y = z, and 3x = 6, so x = y = z = 2.
        lambda = yz = 4

STEP 4  Volume
        V = 2 * 2 * 2 = 8 cubic inches

STEP 5  Global check, two independent ways
        (a) Boundary: if any size is 0 the box is flat and
            V = 0, which is below 8.
        (b) AM-GM: (x + y + z)/3 = 2 >= (xyz)^(1/3)
            so  xyz <= 2^3 = 8, with equality iff x = y = z.
            The bound 8 is attained, so 8 is the GLOBAL max.
        (c) Second derivative of V along the constraint is
            negative, confirming a local max.

CHECK:  Recompute the sheet usage: 2(2) + 2(2) + 2(2) = 12 in
        exactly as required, and the box 2 x 2 x 2 uses all
        12 inches. Answer dimensionally sensible: a cube from
        a fixed sheet is the classical result.
Numeral traps
  • Dividing by a size that may be zero. Going from yz = xz to y = x divides by z. If z = 0 the box is degenerate with V = 0; state that case explicitly before dividing.
  • Setting f_x = f_y = 0 on a constrained problem. That is the unconstrained condition and it is wrong here. The constrained condition is ∇f = λ∇g.
  • Forgetting the constraint in the system. Differentiating F gives three equations, but you still must impose g = 0. Three equations alone leave a one-parameter family of answers.
  • Sign of the multiplier. F = f − λg and F = f + λg both work and give opposite λ. Either is acceptable if you are consistent; mixing them mid-solution is not.
  • Using D > 0 alone to call a minimum. You still need Δ1 > 0 (or f_xx > 0). D > 0 with f_xx < 0 is a maximum.
  • Expanding the 3×3 determinant by hand. 27 terms, guaranteed sign error. Use Δ1, Δ2, Δ3 via Sylvester, and note that a separable f has a diagonal Hessian so D = f_xx f_yy f_zz.
  • One multiplier per constraint. Two constraints need λ and μ, and the candidate points must satisfy both.
  • No closing line. End with the boxed extremum value and one line on why it is global (boundary, AM-GM, or a completing-the-square bound).

Drill set B — Apply (numericals, with answers)
  1. Find and classify the stationary point of f = x² + y² + z² + 2x − 4y + 6z. Ans: f_x = 2x + 2 = 0 → x = −1; f_y = 2y − 4 = 0 → y = 2; f_z = 2z + 6 = 0 → z = −3. All second partials are 2, so H = diag(2,2,2), D = 8 > 0 and f_xx = 2 > 0 → minimum at (−1, 2, −3), f = 1 + 4 + 9 − 2 − 8 − 18 = −14
  2. Find the extrema of f = x² + y² + z² subject to x² + y² + z² = 1. Ans: the constraint is itself a sphere, so f ≡ 1 on it: every point of the sphere is simultaneously a maximum and a minimum. Lagrange: F = f − λ(f−1); 2x(1−λ) = 0, and cyclically, so either λ = 1 (which holds at every feasible point) or x = y = z = 0, which is infeasible. This is the case where λ = 1 and the "extremum" is degenerate — a good viva question.
  3. Maximise f = xy subject to x + y = 10. Ans: F = xy − λ(x+y−10); y = λ, x = λ so x = y = 5; f = 25, a maximum since xy = x(10−x) = 25 − (x−5)^2 ≤ 25
  4. Find the extrema of f = x² + y² + z² subject to x + y + z = 6. Ans: F = x²+y²+z² − λ(x+y+z−6); 2x = 2y = 2z = λ so x = y = z = 2; f = 12. By Cauchy-Schwarz, x²+y²+z² ≥ (x+y+z)²/3 = 12, so 12 is the global minimum. There is no maximum, because the plane x+y+z = 6 is unbounded and f → ∞ along it.
  5. Find the extrema of f = x²y² + y²z² + z²x². Ans: f_x = 2x y^2 + 2z^2 x = 2x(y^2 + z^2) = 0, and cyclically. Either all zero (origin) or, taking all non-zero, y^2+z^2 = z^2+x^2 = x^2+y^2 = 0 which is impossible for non-zero x, so the only real stationary point is (0,0,0) with f = 0, and since f is a sum of squares it is a GLOBAL minimum
Special lines for extra marks
  • Opening line: "To maximise f(xi) subject to g(xi) = 0, form the augmented function F = f − λg and set all partials of F to zero together with g = 0."
  • Geometric line: "At a constrained extremum the surface z = f is tangent to the constraint surface g = 0 without crossing it, so the two share a tangent plane and their normal vectors are parallel: ∇f = λ∇g."
  • Symmetry line: "From yz = xz = xy with x, y, z > 0 we obtain x = y = z, so the extremum of the symmetric product xyz subject to x + y + z = 6 occurs at the cube x = y = z = 2."
  • Limitation line: "Lagrange's method yields candidates only; the boundary of the feasible region must be compared, since a maximum may not exist on an unbounded constraint set — here the boundary gives V = 0 against the interior V = 8."
  • Closing line: "Hence the constrained maximum of V = xyz is 8 cubic inches, attained at the cube 2 × 2 × 2. [boxed]"
Exam tips
  • State the method before using it. Write the augmented function F = f − λg on the first line. It is a mark and it fixes the sign convention.
  • Use Sylvester's criteria, not the raw 3×3 expansion. Three short quantities replace 27 products, and the sign logic becomes obvious.
  • Check for a diagonal Hessian first. A separable f = g(x) + h(y) + k(z) has f_xy = f_xz = f_yz = 0, so D = f_xx f_yy f_zz immediately.
  • Underline the constraint, the multiplier, and the positivity assumption before you divide by a size. Box the extremum value and the point where it occurs.
  • Prove the extremum is global with a one-line check: AM-GM, Cauchy-Schwarz, a completing-the-square bound, or the boundary value. This is the mark that separates a 5 from a 7.
  • Attempt order: unconstrained stationary points (mechanical) → the box/volume problem (everyone can do it) → the abstract "state the method and explain the geometry" question last.

Cheat-Sheet · BT102 Unit 1

Three Variables & Lagrange — Quick Reference

The two statements (write verbatim)

UNCONSTRAINED
  f(x, y, z) has a stationary point where
      f_x = 0 ,  f_y = 0 ,  f_z = 0
  and it is classified by the Hessian
      H = | f_xx  f_xy  f_xz |
          | f_xy  f_yy  f_yz |
          | f_xz  f_yz  f_zz |
  D = |H|:   D > 0 & f_xx > 0 -> MINIMUM
            D > 0 & f_xx < 0 -> MAXIMUM
            D < 0              -> SADDLE
            D = 0              -> inconclusive

CONSTRAINED  (one constraint g = 0)
  Form  F = f - lambda g
  Then  F_x = F_y = F_z = 0   together with   g = 0
  Equivalently  grad f = lambda grad g

Derivation steps — why the gradients must be parallel

1. At a constrained extremum, z = f is tangent to g = 0
   and does NOT cross it.
2. Two surfaces tangent at P share the same tangent plane.
3. Grad f and grad g are both normal to that plane.
4. Two vectors normal to the same plane are parallel:
        grad f = lambda grad g
   Hence proved.

Key definitions

  • Stationary point — a point where all three first partials vanish.
  • Hessian — the symmetric 3×3 matrix of second partials at the point.
  • Saddle point — stationary point with D < 0; neither max nor min.
  • Lagrange multiplier — the scalar λ in ∇f = λ∇g; one per constraint.
  • Augmented function — F = f − λg, whose stationary points are the constrained candidates.
  • Leading principal minor — determinant of the top-left k × k block; drives Sylvester's criterion.

Exam checklist

  • ☐ Did I write all THREE of f_x = f_y = f_z = 0, not just two?
  • ☐ Did I classify with Δ1, Δ2, D rather than expanding 27 terms?
  • ☐ Did I check whether the Hessian is diagonal (separable f) before doing any work?
  • ☐ For a constrained question, did I use F = f − λg and NOT f_x = f_y = 0?
  • ☐ Did I impose the constraint g = 0 alongside the differentiated equations?
  • ☐ Did I state the positivity assumption before dividing by a size?
  • ☐ Did I prove the extremum is global (AM-GM, Cauchy-Schwarz, or boundary check)?
  • ☐ Did I box the value and the point, and add one significance line?

Numeral shortcut

Fastest route through any question on this topic 1. No constraint → write f_x = f_y = f_z = 0, solve, then Δ1, Δ2, D.
2. With a constraint → write F = f − λg, then F_x = F_y = F_z = 0 together with g = 0.
3. Symmetric product or sum → expect x = y = z and skip the algebra.
4. Compare against the boundary (a zero size, or y = 0) to prove the extremum is global.
5. Close with the boxed value, the point, and one AM-GM or Cauchy-Schwarz confirmation line.

Prove it is global two ways: the boundary (any size zero) gives V = 0, and AM-GM gives xyz ≤ ((x+y+z)/3)³ = 8 with equality at x = y = z. Close by noting the optimum is a cube.

write — constraint reduced + augmented F (1) → three differentiated equations with the constraint (2) → positivity note and x = y = z = 2 (1) → V = 8 boxed (1) → boundary and AM-GM justification (2).
check — the multiplier equations alone leave a family until the constraint is imposed; 2 × 2 × 2 = 8 in cubic inches, and the AM-GM line is what earns the final mark.
Q35 marks · 12 min★★ frequent

Explain, with a diagram, why ∇f = λ∇g at a constrained extremum of f subject to g = 0

Start with the observation that on the constraint surface g = 0 the function z = f can only reach a maximum or minimum at a point where it just touches the surface instead of crossing it. Two surfaces that touch without crossing share a tangent plane at the contact point. Now ∇f and ∇g are both normal to that shared plane, and two vectors normal to the same plane are parallel, so ∇f = λ∇g for some scalar λ. Draw a dome tangent to a plane, mark the contact point, and draw both normals. Add the complement: where the two surfaces cross, the normals are not parallel and the plain conditions f_x = f_y = 0 apply instead.

write — tangency observation (1) → shared tangent plane (1) → both gradients normal to it (1) → parallelism and the conclusion (1) → labelled diagram (1).
check — the diagram must show the surfaces touching and NOT crossing, with both normals drawn at the contact point; stating the result without the geometric argument loses the reasoning marks.
Topper answer format
  1. Statement: Write the stationary condition or the augmented function F = f − λg on the first line, before any derivative.
  2. Visual: For Lagrange, draw the tangency diagram; for classification, give the criteria table with the three signs filled in.
  3. Reason: Number the steps — condition, solve, evaluate, classify — and state any assumption you divide on.
  4. Close: Box the value and the point, then add one line proving the extremum is global (AM-GM, Cauchy-Schwarz, or boundary).

Model opening: "To maximise f(x₁, …, xₙ) subject to g(x₁, …, xₙ) = 0, introduce the multiplier λ and consider the augmented function F = f − λg. Setting all partial derivatives of F equal to zero, together with the constraint, gives the system whose solutions are the constrained stationary points."

For this topic: condition or augmented function → solve the system → classify with Δ1/Δ2/D, or equating the multiplier equations → box the value and point → one global-extremum justification line.

Find and classify the stationary point of f = x² + y² + z² − 2x + 4y − 6z + 11

All second partials of a separable quadratic are constants, so the Hessian is diagonal and the classification is immediate.

  f = x^2 + y^2 + z^2 - 2x + 4y - 6z + 11
  ==========================================================
   STEP 1   THREE FIRST PARTIALS, ALL SET TO ZERO
  ----------------------------------------------------------
        f_x = 2x - 2 = 0    ->  x =  1
        f_y = 2y + 4 = 0    ->  y = -2
        f_z = 2z - 6 = 0    ->  z =  3
                       one candidate:  (1, -2, 3)
  ----------------------------------------------------------
   STEP 2   HESSIAN IS CONSTANT AND DIAGONAL
  ----------------------------------------------------------
        f_xx = 2   f_xy = 0   f_xz = 0
        f_yy = 2   f_yz = 0   f_zz = 2

              +---+---+---+
              | 2 | 0 | 0 |
              +---+---+---+
        H  =  | 0 | 2 | 0 |     diagonal, so no 27-term
              +---+---+---+     expansion is needed
              | 0 | 0 | 2 |
              +---+---+---+

        D = 2 * 2 * 2 = 8
  ----------------------------------------------------------
   STEP 3   SYLVESTR'S CRITERIA
  ----------------------------------------------------------
        Delta1 = f_xx            = 2    > 0
        Delta2 = f_xx f_yy - f_xy^2 = 4  > 0
        Delta3 = D                = 8    > 0
        all three positive -> Hessian positive definite
        -> LOCAL MINIMUM
  ----------------------------------------------------------
   STEP 4   COMPLETE THE SQUARE  (the global check)
  ----------------------------------------------------------
        f = (x - 1)^2 + (y + 2)^2 + (z - 3)^2 - 3
                                   |
              each square >= 0      |
              therefore f >= -3, equality ONLY at (1, -2, 3)
                                   |
                                   v
        so the MINIMUM IS GLOBAL and its VALUE IS -3
  ==========================================================
  1. Stationary condition: f_x = 2x − 2 = 0 gives x = 1, f_y = 2y + 4 = 0 gives y = −2, and f_z = 2z − 6 = 0 gives z = 3, so the unique candidate is (1, −2, 3).
  2. Hessian: all second partials are constants, with f_xx = f_yy = f_zz = 2 and all mixed partials zero, so H = diag(2, 2, 2) and D = 8.
  3. Classification by Sylvester's criterion: Δ1 = 2 > 0, Δ2 = (2)(2) − 0 = 4 > 0, D = 8 > 0, so the point is a local minimum.
  4. Value: f(1, −2, 3) = 1 + 4 + 9 − 2 − 8 − 18 + 11 = −3.
  5. Independent global check: completing the square gives f = (x−1)² + (y+2)² + (z−3)² − 3. Every square is non-negative, so f ≥ −3 with equality only at (1, −2, 3) — the minimum is global, not merely local.

Exam close: box "f has a global minimum −3 at (1, −2, 3)" and write the completing-the-square form as the justification.

Model answer · 7 marks

Using Lagrange's multipliers, find the largest box that can be made from 12 inches of sheet metal, 2x + 2y + 2z = 12

The constraint reduces to a symmetric sum, so the symmetric product xyz is largest when the three sizes are equal — a cube.

  LARGEST BOX FROM 12 in OF SHEET
  ==========================================================
   2x + 2y + 2z = 12   ->   x + y + z = 6      (sheet cost)
   maximise  V = x y z                          (volume)
  ==========================================================
   AUGMENTED FUNCTION     (one constraint, so one lambda)
  ----------------------------------------------------------
        F = x y z  -  lambda ( x + y + z - 6 )
  ==========================================================
   DIFFERENTIATE   F_x = F_y = F_z = 0   WITH   x+y+z = 6
  ----------------------------------------------------------
        F_x = y z - lambda = 0     ->  yz = lambda
        F_y = x z - lambda = 0     ->  xz = lambda
        F_z = x y - lambda = 0     ->  xy = lambda
        g   = x + y + z - 6 = 0
  ----------------------------------------------------------
   NOTE: a non-degenerate box has x, y, z > 0, so dividing
         by a size is legitimate. (If a size were 0 then
          V = 0 and it cannot be the maximiser.)
  ==========================================================
   EQUATE THE THREE           3x = 6
  ----------------------------------------------------------
        yz = xz  ->  z(y - x) = 0  ->  y = x
        xz = xy  ->  x(z - y) = 0  ->  z = y
                                    |
                                    v
                          x = y = z = 2
                          lambda = yz = 4
  ==========================================================
   VOLUME      V = 2 * 2 * 2 = 8 cubic inches       [BOXED]
                check sheet: 2(2)+2(2)+2(2) = 12 in, exact
  ----------------------------------------------------------
   IS IT GLOBAL?  two independent confirmations
  ----------------------------------------------------------
   (a) BOUNDARY: a zero size gives V = 0, below 8.
   (b) AM-GM:   (x+y+z)/3 = 2  >=  (xyz)^(1/3)
               so  xyz <= 8, with equality iff x = y = z.
   Both bound V from above by 8, and 8 is attained, so
   8 is the GLOBAL maximum and the box is a CUBE.
  ==========================================================
  1. Reduce the constraint: divide 2x + 2y + 2z = 12 by 2 to get x + y + z = 6, and take V = xyz as the function to maximise.
  2. Augmented function: F = xyz − λ(x + y + z − 6).
  3. System: yz = λ, xz = λ, xy = λ from the partials, together with the constraint x + y + z = 6.
  4. Solve: since the sizes are positive, yz = xz gives y = x and xz = xy gives z = y, so x = y = z and 3x = 6 gives x = y = z = 2, with λ = 4.
  5. Volume and global check: V = 8 cubic inches. The boundary case of a zero size gives V = 0, and AM-GM gives xyz ≤ ((x+y+z)/3)³ = 8 with equality at x = y = z, so 8 is the global maximum and the box is a cube.

Exam close: box "Vmax = 8 cubic inches at x = y = z = 2" and write "the largest box is a cube, confirmed by AM-GM since xyz ≤ ((x+y+z)/3)³."

Model answer · 5 marks

Explain, with a diagram, why ∇f = λ∇g at a constrained extremum of f subject to g = 0

The explanation is geometric: the optimum is where the two surfaces touch rather than cross, and touching surfaces share a tangent plane.

  CONSTRAINED EXTREMUM  =  TANGENCY, NOT CROSSING
  ==========================================================
        z
        ^
        |             surface  z = f(x, y)     a dome
        |                 .-'''''''-.
        |              .-'    .-----.  '-.
        |           .-'     .'       '.   '-.
        |        .-'      .'     P       '.   '-.   surfaces
        |      .'        .'     (0,0)      '.     '.  TOUCH here
        |     /         /         |          \      \
        +----|---------|---------|-----------|------|----> y
             |         |         |           |      |
        =====|=========|=========|===========|======|====  plane
             |         |         |           |      |     g = 0
        -----|---------|---------|-----------|------|-----  (no
             |         |         |           |      |      crossing)
  ==========================================================
   AT P   both surfaces share ONE tangent plane, so
          both gradients are NORMAL to that same plane:

              grad f  =  lambda * grad g
                 ^                 ^
                 |                 |
                 +-------->        +-------->
                       parallel, not equal
  ----------------------------------------------------------
   IF THEY CROSSED at P, the tangent planes would differ,
   the normals would NOT be parallel, and P would not be a
   constrained extremum. That crossing case is what the
   unconstrained conditions f_x = f_y = 0 are for instead.
  ----------------------------------------------------------
   Special case: lambda = 0  means  grad f = 0, i.e. an
   unconstrained stationary point that happens to satisfy
   the constraint. Those are genuine candidates too and
   must be tested as well.
  ==========================================================
  1. The observation: on the constraint surface g = 0, a maximum or minimum of z = f(x, y) can occur only where the surface just touches the constraint surface rather than crossing it. Crossing points allow movement to larger and smaller values along the surface.
  2. Shared tangent plane: two surfaces that touch without crossing are tangent at the contact point, so they have the same tangent plane there.
  3. Normals: ∇f and ∇g are both normal to that shared tangent plane.
  4. Conclusion: two vectors normal to the same plane are parallel, hence ∇f = λ ∇g for some scalar λ. This is exactly the condition Lagrange's method enforces, and it is why the augmented function F = f − λg has zero gradient at the constrained extremum.
  5. Complement and edge case: where the two surfaces cross, the normals are not parallel and the unconstrained conditions apply; and λ = 0 recovers an unconstrained stationary point that also satisfies the constraint, which must still be tested.

Exam close: box "∇f = λ∇g" and close with "the surfaces are tangent at the extremum, not crossing, so their normals are parallel."
