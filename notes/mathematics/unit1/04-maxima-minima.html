Lesson · BT102 Unit 1 — Calculus

Maxima & Minima of Two Variables — Find Peaks and Valleys on a Surface

You've mastered single-variable optimization. Now we go 2D: functions like f(x,y) = x² + y² define surfaces, not curves. The peaks are maxima, the troughs are minima, and the mountain passes are saddle points. RGPV BT102 asks you to find and classify all three.

The setup

A function f(x, y) has a stationary point where both partial derivatives vanish:

fx = ∂f/∂x = 0    AND    fy = ∂f/∂y = 0

Stationary points can be: maximum, minimum, or saddle point (neither).

The second derivative test (your classification tool)

Define the discriminant D (also called the Hessian determinant):

Let:  r = fxx,  s = fxy,  t = fyy

Then: D = r·t − s² = fxx · fyy − (fxy)²
ConditionClassification
D > 0 and r > 0Local minimum
D > 0 and r < 0Local maximum
D < 0Saddle point (neither max nor min)
D = 0Test is inconclusive — need higher-order analysis
Memory trick D > 0 means "definite" (either max or min) — the sign of r tells you which. D < 0 means "saddle" — think of a horse saddle: up in one direction, down in another.

The 5-step algorithm (RGPV marking scheme)

Step 1: Find fx and fy (first partial derivatives)
Step 2: Solve fx = 0 AND fyxx, s = fxy, t = fyy at each stationary point
Step 4: Calculate D = rt − s²
Step 5: Classify using the table above

Example 1 — the classic PYQ

Q: Find the maxima/minima/saddle points of f(x,y) = x² + y² + 2x + 4y + 5.

StepWork
1fx = 2x + 2, fy = 2y + 4
22x + 2 = 0 → x = -1; 2y + 4 = 0 → y = -2
3r = fxx = 2, s = fxy = 0, t = fyy = 2
4D = (2)(2) - (0)² = 4
5D = 4 > 0, r = 2 > 0 → Local minimum at (−1, −2)
  f(x,y) = x² + y² + 2x + 4y + 5

Example 2 — with a saddle point

Q: Classify stationary points of f(x,y) = x² − y².

StepWork
1fx = 2x, fy = -2y
22x = 0 → x = 0; -2y = 0 → y = 0 → point (0,0)
3r = 2, s = 0, t = -2
4D = (2)(-2) - (0)² = -4
5D = -4 < 0 → Saddle point at (0, 0)
  f(x,y) = x² - y²  (hyperbolic paraboloid)

Example 3 — product term (s ≠ 0)

Q: Find stationary points of f(x,y) = x³ + y³ − 3xy.

StepWork
1fx = 3x² - 3y, fy = 3y² - 3x
23x² = 3y → y = x²; 3y² = 3x → y² = x
3Substituting: (x²)² = x → x&sup4; = x → x(x³-1)=0
4x = 0 → y = 0; x = 1 → y = 1 → points (0,0) and (1,1)
5At (0,0): r=0, s=-3, t=0, D = 0 - 9 = -9 < 0 → saddle
6At (1,1): r=6, s=-3, t=6, D = 36-9 = 27 > 0, r=6 > 0 → min
Exam tip — common RGPV functions - x² + y²: always has a minimum (paraboloid bowl) - x² - y²: always has a saddle (hyperbolic paraboloid) - x³ + y³ - 3xy: the "fool's saddle" problem (two stationary points) - xy: pure saddle at origin - Product terms (xy) make s ≠ 0, which makes D harder to compute

Cheat-Sheet · BT102 Unit 1

Maxima & Minima — Quick Reference

The algorithm (5 steps)

1. fx = 0, fy = 0  → find stationary points
2. r = fxx, s = fxy, t = fyy
3. D = rt − s²
4. Classify using the table below

Classification table

ConditionResult
D > 0, r > 0Local minimum
D > 0, r < 0Local maximum
D < 0Saddle point
D = 0Inconclusive (need higher-order test)

Common functions & their behavior

f(x,y)Stationary pointClassification
x² + y²(0, 0)Minimum
-x² - y²(0, 0)Maximum
x² - y²(0, 0)Saddle
xy(0, 0)Saddle
x³ + y³ - 3xy(0,0), (1,1)Saddle, Minimum

Key definitions

  • Stationary point: where fx = 0 AND fy = 0
  • Saddle point: stationary point that is neither max nor min
  • Discriminant: D = fxx·fyy − (fxy)²

Exam checklist

  • ☐ Did I find BOTH partial derivatives (f_x and f_y)?
  • ☐ Did I solve them simultaneously (both = 0)?
  • ☐ Did I compute r, s, t at EACH stationary point?
  • ☐ Did I use D = rt - s² (not r + t)?
  • ☐ Did I classify correctly (check both D and r sign)?
