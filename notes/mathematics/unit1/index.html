Terminal quick reference 
f(x) = f(a) + (x-a)f'(a) + (x-a)²/2! f"(a) + ...  [Taylor]
sin x = x - x³/3! + x&sup5;/5! - ...                [Maclaurin]
cos x = 1 - x²/2! + x&sup4;/4! - ...               [Maclaurin]
e³x  = 1 + x + x²/2! + x³/3! + ...          [Maclaurin]
