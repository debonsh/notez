Lagrange's Mean Value Theorem — The Generalization of Rolle's

You've nailed Rolle's. Now it's time to level up. Lagrange's Mean Value Theorem (LMVT) is Rolle's big brother — it drops the f(a)=f(b) restriction and works for ANY continuous, differentiable function. It's a guaranteed 5–7 mark question in RGPV BT102, and it builds directly on what you already know.

The statement

Let f(x) be a real-valued function defined on [a, b]. If these two conditions hold:

#ConditionWhat to check
1f is continuous on [a, b]No breaks, jumps, or asymptotes
2f is differentiable on (a, b)No sharp corners or cusps

Then there exists at least one point c ∈ (a, b) such that

f′(c) = f(b) − f(a) / b − a

The one-second intuition Somewhere on the curve, the tangent is parallel to the secant line connecting (a, f(a)) and (b, f(b)). The slope of that secant = average rate of change. LMVT says: "there's at least one instant where the instantaneous rate equals the average rate."
Why this generalizes Rolle's Rolle's theorem is just LMVT where f(a) = f(b). When endpoints are equal, the secant slope is zero, and LMVT becomes "f'(c) = 0" — exactly Rolle's conclusion. LMVT removes that restriction and works for ANY endpoints.

The verification recipe (5 steps, 7 marks)

Step 1: Identify [a, b]
Step 2: Confirm continuity on [a, b]
Step 3: Confirm differentiability on (a, b)
Step 4: Compute secant slope = (f(b) - f(a)) / (b - a)
Step 5: Set f'(c) = secant slope, solve for c, verify c ∈ (a, b)

Example 1 — the classic PYQ (x² on [1, 3])

Q: Verify Lagrange's MVT for f(x) = x² on [1, 3].

StepWork
1[a, b] = [1, 3]
2Polynomial → continuous on [1, 3]
3Polynomial → differentiable on (1, 3)
4f(1) = 1, f(3) = 9; secant slope = (9−1)/(3−1) = 4
5f'(x) = 2x; 2c = 4 → c = 2 ∈ (1, 3) → Verified

Example 2 — cubic (x³ on [0, 2])

Q: Verify LMVT for f(x) = x³ on [0, 2].

StepWork
1[a, b] = [0, 2]
2, 3Polynomial → continuous & differentiable
4f(0) = 0, f(2) = 8; secant slope = (8−0)/(2−0) = 4
5f'(x) = 3x²; 3c² = 4 → c = 2/√3 ≈ 1.15 ∈ (0, 2) → Verified

Example 3 — trigonometric (sin x on [0, π/2])

Q: Verify LMVT for f(x) = sin x on [0, π/2].

StepWork
2, 3sin x is continuous & differentiable everywhere
4f(0) = 0, f(π/2) = 1; secant slope = (1−0)/(π/2−0) = 2/π
5f'(x) = cos x; cos c = 2/π → c = arccos(2/π) ≈ 0.88 ∈ (0, π/2) → Verified
Pattern to notice LMVT loves x², x³, and sin x on simple intervals. The key skill: computing the secant slope correctly and solving f'(c) = that value. Unlike Rolle's, c is RARELY a clean integer — expect fractions or trig inverses.

Lagrange's MVT — Quick Reference

The statement

Geometric meaning

  • There's at least one point where the tangent is parallel to the secant.
  • Slope of secant = average rate of change over [a,b].
  • Slope of tangent at c = instantaneous rate at c.
  • LMVT: "at some instant, instantaneous rate = average rate."

  • ☐ Did I compute (f(b)-f(a))/(b-a) correctly?
  • ☐ Did I set f'(c) equal to the secant slope (not zero)?
  • ☐ Is c actually inside (a,b)?
  • ☐ Did I write "Hence LMVT is verified"?
