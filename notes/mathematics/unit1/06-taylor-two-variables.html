Lesson · BT102 Unit 1 — Calculus

Taylor's Theorem in Two Variables — The Surface Version of a Series

Syllabus item 5 of Module 1: "Taylor's theorem for function of two variables". Topic 03 expanded a curve; this topic expands a surface. The jump in difficulty is real but manageable: the one-variable formula simply appears once for every total order, and the mixed partials come from topic 05.

Statement (write verbatim)

Let f(x, y) be defined in a neighbourhood of (a, b) and possess
partial derivatives of all orders up to n in that neighbourhood.
Put   h = x - a,  k = y - b.

Then for (x, y) near (a, b):

  f(x, y) = f(a, b)
          + [ f_x(a,b) h + f_y(a,b) k ]
          + 1/2! [ f_xx h^2 + 2 f_xy h k + f_yy k^2 ]
          + 1/3! [ f_xxx h^3 + 3 f_xxy h^2 k + 3 f_xyy h k^2 + f_yyy k^3 ]
          + ... + a remainder term

The n-th order group is  1/n! * (h d/dx + k d/dy)^n f  (Euler operator).
The one thing that makes this topic tractable Read each line as a total order, not as a term count. The zeroth line has one term, the first line has two, the second has three, the third has four. RGPV almost never asks beyond the second-order line — so learn the first three lines cold and treat the third-order line as bonus.

The three lines you must be able to write instantly

ZEROTH ORDER
  f(a, b)

FIRST ORDER  (the tangent plane)
  f(a, b) + f_x(a,b) h + f_y(a,b) k

SECOND ORDER  (the quadratic surface)
  f(a, b) + f_x h + f_y k
         + 1/2 [ f_xx h^2 + 2 f_xy h k + f_yy k^2 ]
TermCountWhere the coefficients come from
zeroth1f itself
first2f_x, f_y
second3f_xx, f_xy, f_yy — note the 2 in front of the mixed term
third4binomial coefficients 1, 3, 3, 1

Why the 2 in front of the mixed term

The mixed term carries the coefficient 2 f_xy h k / 2! = f_xy h k. It appears twice because the cross product hk can be formed in two orders, dx dy and dy dx, and by Schwarz' theorem those are equal. Writing the full second-order group without the 2 is the single most common error on this topic.

  TAYLOR IN TWO VARIABLES  --  count by TOTAL ORDER
  =========================================================
   h = x - a ,  k = y - b

   ORDER 0   1 term        f(a, b)
                    |
   ORDER 1   2 terms       f_x(a,b) h  +  f_y(a,b) k
                    |
   ORDER 2   3 terms       1/2 [ f_xx h^2  +  2 f_xy h k
                                        +  f_yy k^2 ]
                    |
   ORDER 3   4 terms       1/6 [ f_xxx h^3
                                 + 3 f_xxy h^2 k
                                 + 3 f_xyy h k^2
                                 +   f_yyy k^3 ]
  =========================================================
   COEFFICIENTS WITHIN A LINE are the binomial row:
      order 0 : 1
      order 1 : 1 1
      order 2 : 1 2 1
      order 3 : 1 3 3 1
   The 2 in order 2 exists because hk can be reached by
   dx then dy, or dy then dx -- Schwarz says both are f_xy.
  =========================================================
   COMPACT FORM:  1/n! ( h d/dx + k d/dy )^n f
   This is Euler's operator and generates every line above.

Maclaurin in two variables is just a = 0, b = 0

f(x, y) = f(0, 0) + (f_x) x + (f_y) y
                   + 1/2 [ f_xx x^2 + 2 f_xy x y + f_yy y^2 ] + ...
(all partials evaluated at the origin)

Memorize the common ones:
  e^(x + y) = 1 + (x + y) + (x + y)^2/2! + ...
            = 1 + x + y + 1/2 (x^2 + 2xy + y^2) + ...
  e^x e^y   = the same thing, since e^(x+y) = e^x e^y
  sin(x + y), cos(x + y)  -- expand the bracket, same rule

Standalone pairs (NOT functions of x + y, so different):
  e^(xy)    = 1 + xy + (xy)^2/2! + ...      <- no x^2, no y^2
  sin(x)cos(y) = (x - x^3/6 + ...)(1 - y^2/2 + ...)
               = x + x y^2/2 - x^3/6 - ...  <- cross terms only
Read the distinction: a function of x + y expands as a Taylor series in the single variable u = x + y, so all powers of x and y appear. A function of xy like e^(xy) expands in powers of the product, so only xy, x²y², x³y³ appear and never a lone x². Deciding which case you are in is the first step of every question on this topic.

Deriving the two-variable result from the one-variable theorem

For fixed k, treat y = b + k as a CONSTANT and apply the
one-variable Taylor theorem to f(., b + k) in x about x = a:

  f(x, b + k) = f(a, b + k)
              + f_x(a, b + k) h
              + 1/2 f_xx(a, b + k) h^2 + ...

Now expand EACH piece about b, in powers of k:

  f(a, b + k)     = f(a,b)   + f_y(a,b) k   + 1/2 f_yy(a,b) k^2 + ...
  f_x(a, b + k)   = f_x(a,b) + f_xy(a,b) k  + ...
  f_xx(a, b + k)  = f_xx(a,b)+ f_xxy(a,b) k + ...

Collecting every term of TOTAL order 2:

  f(a,b) + f_x h + f_y k
    + 1/2 f_xx h^2
    + 1/2 * 2 f_xy h k        <-  f_x * k gives f_xy h k,
    + 1/2 f_yy k^2               and it is NOT halved, because
                                 the 1/2 of the x-expansion and
                                 the 1/2 of the y-expansion are
                                 different 1/2's being multiplied
  which is exactly the second-order line.  QED

Numericals in great depth

Every question on this topic is "evaluate all the required partials at one point, then assemble the right number of lines". The whole difficulty is bookkeeping, so the identifier table and the check line are what earn the marks.

Solved A — f(x,y) = x² + xy + y² at (1, 1) to second order

Given:   f(x, y) = x^2 + x y + y^2 ,  expand about (a, b) = (1, 1)
         up to second order terms
Find:    the two-variable Taylor expansion
Formula: V5  1/2 f_xx h^2 + f_xy h k + 1/2 f_yy k^2

STEP 1  The shifts
        h = x - 1 ,  k = y - 1
        So x = 1 + h and y = 1 + k.

STEP 2  Partials at the point (1, 1)
        f_x  = 2x + y       ->  f_x(1,1)  = 2(1) + 1 = 3
        f_y  = x + 2y       ->  f_y(1,1)  = 1 + 2(1) = 3
        f_xx = 2            ->  f_xx(1,1) = 2
        f_xy = 1            ->  f_xy(1,1) = 1
        f_yy = 2            ->  f_yy(1,1) = 2
        f(1, 1) = 1 + 1 + 1 = 3

STEP 3  Assemble
        f = 3
          + 3h + 3k
          + 1/2(2) h^2 + (1) h k + 1/2(2) k^2
          = 3 + 3h + 3k + h^2 + h k + k^2

STEP 4  Substitute back h = x - 1, k = y - 1
        f = 3 + 3(x - 1) + 3(y - 1)
              + (x - 1)^2 + (x - 1)(y - 1) + (y - 1)^2
          = 3 + 3x - 3 + 3y - 3
              + (x^2 - 2x + 1) + (xy - x - y + 1)
              + (y^2 - 2y + 1)
          = x^2 + xy + y^2 + (3x - 2x - x) + (3y - y - 2y)
              + (3 - 3 - 3 + 1 + 1 + 1)
          = x^2 + x y + y^2 + 0 + 0 + 0
          = x^2 + x y + y^2                    EXACT

CHECK:  Step 4 returns the ORIGINAL polynomial, not merely an
        approximation. That is the tell-tale of a quadratic f:
        the series terminates. Set h = k = 0 and the expansion
        collapses to f(1,1) = 3, as it must. Coefficient count
        is 1, 2, 3 -- correct for orders 0, 1, 2.
Check note — the trap in Solved A If you skip the substitution back to x and y, your answer is still a valid expansion but it reads as an expression in h and k, which many examiners do not accept as "expanded in powers of (x−a) and (y−b)". Always finish by writing h = x − a, k = y − b back in. And a quadratic f has an exact series that terminates — if your expansion still has an h³ or k³ term, you over-differentiated.

Solved B — f(x,y) = e^(xy) at the origin to second order

Given:   f(x, y) = e^(x y) ,  expand about (a, b) = (0, 0)
Find:    the Maclaurin expansion to second order
Formula: V1  h = x, k = y at the origin

STEP 1  Read the structure first
        e^(xy) depends on x and y only through the PRODUCT xy.
        So the series is a series in xy:
        e^(xy) = 1 + xy + (xy)^2/2! + (xy)^3/3! + ...
        There is NO x^2 term and NO y^2 term. Deciding this
        first saves two useless derivatives.

STEP 2  Confirm with the partials at (0, 0)
        f    = e^(xy)          f(0,0)   = 1
        f_x  = y e^(xy)        f_x(0,0) = 0
        f_y  = x e^(xy)        f_y(0,0) = 0
        f_xx = y^2 e^(xy)      f_xx(0,0)= 0
        f_xy = (1 + xy) e^(xy) f_xy(0,0)= 1
        f_yy = x^2 e^(xy)      f_yy(0,0)= 0

STEP 3  Assemble with h = x, k = y
        f = 1 + (0) x + (0) y
              + 1/2(0) x^2 + (1) x y + 1/2(0) y^2
          = 1 + x y

STEP 4  The true series, for comparison
        e^(xy) = 1 + xy + (xy)^2/2! + (xy)^3/3! + ...
               = 1 + xy + x^2 y^2/2 + x^3 y^3/6 + ...

CHECK:  The second-order group is exactly 1 + xy, because the
        next surviving term is (xy)^2/2 = x^2 y^2/2, which is
        TOTAL ORDER 4, not order 2. That is the whole lesson:
        order is the TOTAL degree, so x^2 y^2 is a
        fourth-order term. Numerical check at (0.1, 0.2):
          exact  e^0.02            = 1.0202013
          second order  1 + (0.02) = 1.02
        agreement to two decimals, as expected.
Read the arithmetic: "second order" in x and y together means every monomial of total degree ≤ 2. For e^(xy) the only such monomial is xy, so the whole second-order group collapses to one term. If your answer contains x² or y² here, your derivatives were wrong, not your order.

Solved C — f(x,y) = sin(x + y) at (π/6, π/6) to first order, and the tangent-plane estimate

Given:   f(x, y) = sin(x + y) ,  about (a, b) = (pi/6, pi/6)
Find:    the first-order expansion, then estimate f at
         (x, y) = (pi/4, pi/3) and comment on the error
Formula: f ~ f(a,b) + f_x(a,b) h + f_y(a,b) k

STEP 1  The shifts
        h = x - pi/6 ,  k = y - pi/6
        x + y = (pi/6 + h) + (pi/6 + k) = pi/3 + h + k

STEP 2  Partials at the point
        f    = sin(x + y)          f(pi/6,pi/6)   = sin(pi/3) = sqrt3/2
        f_x  = cos(x + y)          f_x(pi/6,pi/6) = cos(pi/3) = 1/2
        f_y  = cos(x + y)          f_y(pi/6,pi/6) = cos(pi/3) = 1/2

STEP 3  Assemble
        f ~ sqrt3/2 + 1/2 h + 1/2 k

STEP 4  Estimate at (pi/4, pi/3)
        h = pi/4 - pi/6 = pi/12
        k = pi/3 - pi/6 = pi/6
        f ~ sqrt3/2 + 1/2 (pi/12) + 1/2 (pi/6)
           = 0.8660254 + 0.1308997 + 0.2617994
           = 1.2587245

CHECK:  Exact value is sin(pi/4 + pi/3) = sin(7pi/12).
        7pi/12 = 105 degrees, and sin 105 deg = 0.9659258.
        The linear estimate 1.2587245 EXCEEDS the true value
        0.9659258 by 0.29287. That is not a small error, and
        the reason is worth writing: the h and k steps here are
        large (pi/12 and pi/6 are not infinitesimal), so a
        first-order approximation is simply not valid this far
        from the centre. Rule: first-order is safe only for
        SMALL h and k; otherwise add the second-order group.
        This is the limitation the examiner wants named.
Numeral traps
  • Forgetting the 2 in 2 f_xy hk. After dividing by 2! the mixed term is simply f_xy hk. Writing 1/2 f_xy hk halves the cross term and is the most common error on this topic.
  • Confusing total order with the exponent of one variable. In e^(xy) the term x²y² is order 4, not 2. Count a + b in x^a y^b.
  • Not substituting back. The answer must end in powers of (x − a) and (y − b) or in x, y — not left in h and k with the shifts undefined.
  • ∂/∂y (x²) = 0, not 2x. Pure powers of the other variable differentiate to zero. This kills f_y for e^(xy) at the origin and is how you get 1 + xy.
  • Evaluating the partials at the wrong point. They go at the centre (a, b), not at the point you are estimating. For a tangent-plane estimate that swap produces a plausible but wrong number.
  • Over-differentiating a polynomial. A degree-2 f has a finite series; f_xxx = 0 and the expansion terminates exactly. Extra terms mean a miscounted order.
  • Claiming first-order is always accurate. It is a local statement. Say the estimate is valid for small h, k and name the error otherwise.

PYQ drill

Drill set A — Expand (theory)
  1. Expand f(x, y) = x² + xy + y² in powers of (x − 1) and (y − 1) up to second order. (Jun 2023 pattern)
  2. State Taylor's theorem for a function of two variables and write its first three lines. (Dec 2023 pattern)
  3. Expand e^(x + y) in ascending powers of x and y up to terms of total degree 2. (Jun 2024 pattern)
  4. Show that e^(x+y) = e^x e^y by comparing their two-variable expansions. (Dec 2024 pattern)
  5. Why does the expansion of e^(xy) contain no x² or y² term? (Jun 2025 pattern)
Drill set B — Apply (numericals, with answers)
  1. Find the second-order expansion of f = x²y about (1, 2). Ans: f = 2; f_x = 2xy = 4, f_y = x² = 1, f_xx = 2y = 4, f_xy = 2x = 2, f_yy = 0. With h = x−1, k = y−2: f = 2 + 4h + k + 2h² + 2hk
  2. Expand sin(x + y) about (0, 0) to total order 2. Ans: f = 0, f_x = f_y = 1, f_xx = f_xy = f_yy = 0, so f = x + y exactly — the series is sin(x+y) and only odd total orders survive
  3. Find the tangent-plane estimate of f = x² + y² at (2, 1) for the point (2.1, 1.05). Ans: f(2,1) = 5, f_x = 2x = 4, f_y = 2y = 2; h = 0.1, k = 0.05; estimate = 5 + 0.4 + 0.1 = 5.5. Exact = 4.41 + 1.1025 = 5.5125, so the error is 0.0125
  4. Expand ln(1 + x + y) about (0, 0) to total order 2. Ans: with u = x + y, ln(1+u) = u − u²/2, so f = (x + y) − (x + y)²/2 = x + y − (x² + 2xy + y²)/2 = x + y − x²/2 − xy − y²/2
  5. Expand (1 + x + y)³ about (0, 0) to total order 2. Ans: with u = x + y, (1+u)^3 = 1 + 3u + 3u², so f = 1 + 3(x + y) + 3(x² + 2xy + y²) = 1 + 3x + 3y + 3x² + 6xy + 3y²
Special lines for extra marks
  • Opening line: "Let f(x, y) possess partial derivatives of all orders up to n near (a, b), and put h = x − a, k = y − b. Then by Taylor's theorem for two variables, f(x, y) equals the sum of the total-order groups, the r-th being 1/r! (h∂x + k∂y)^r f evaluated at (a, b)."
  • Coefficient line: "The mixed term carries the coefficient 2 f_xy because hk is reached by two routes, ∂x∂y and ∂y∂x, which Schwarz' theorem makes equal; the 2! then cancels it, leaving f_xy hk."
  • Order line: "A monomial x^a y^b belongs to total order a + b, which is why x²y² in the series for e^(xy) is a fourth-order term and does not appear in the second-order group."
  • Limitation line: "The first-order expansion is the tangent plane and is therefore a local result; at (π/4, π/3) the steps h = π/12, k = π/6 are not small, and the linear estimate 1.2587 overshoots the true value 0.9659 by 0.2928."
  • Closing line: "Hence the second-order expansion of e^(xy) at the origin is 1 + xy. [boxed]"
Exam tips
  • State the theorem first, then define h and k. The shifts are a mark and they make every later line shorter.
  • Put a partials table in the answer — f, f_x, f_y, f_xx, f_xy, f_yy each with its value at (a, b). The examiner awards from the table, and it stops you evaluating anything twice.
  • Count total order out loud in the margin: 1, 2, 3. It is the fastest way to catch a missing or extra term.
  • Underline h = x − a and k = y − b; box the final expansion. Substitute h = k = 0 as a last check that you return f(a, b).
  • Attempt order: polynomial f first (it terminates, so it is short and exact) → then e^(x+y) / sin(x+y) → then e^(xy)-type, which is where the order counting bites.
  • Never leave blank: the statement plus the partials table is 40% of any question, and both are pure recall.

Cheat-Sheet · BT102 Unit 1

Taylor in Two Variables — Quick Reference

The statement (write verbatim)

Put h = x - a,  k = y - b.  Then near (a, b):

f(x, y) = f(a,b)
        + [ f_x h + f_y k ]
        + 1/2! [ f_xx h^2 + 2 f_xy h k + f_yy k^2 ]
        + 1/3! [ f_xxx h^3 + 3 f_xxy h^2 k + 3 f_xyy h k^2 + f_yyy k^3 ]
        + ...

Compact:   order r  =  1/r! ( h d/dx + k d/dy )^r f
All partials on the right are evaluated at (a, b).

Derivation steps — from the one-variable theorem

1. Fix k, treat y = b + k as constant, apply 1-variable Taylor
   in x about a:      f(x, b+k) = f(a,b+k) + f_x(a,b+k) h
                                        + 1/2 f_xx(a,b+k) h^2 + ...
2. Expand each piece about b in powers of k:
      f(a, b+k)    = f(a,b)   + f_y(a,b) k  + 1/2 f_yy(a,b) k^2 + ...
      f_x(a, b+k)  = f_x(a,b) + f_xy(a,b) k + ...
      f_xx(a, b+k) = f_xx(a,b)+ f_xxy(a,b) k + ...
3. Collect terms of TOTAL order 2:
      f(a,b) + f_x h + f_y k + 1/2 f_xx h^2 + f_xy h k + 1/2 f_yy k^2
4. Hence proved.

Key definitions

  • Total order — for x^a y^b it is a + b; order is not the exponent of one variable.
  • Tangent plane — the first-order expansion, f(a,b) + f_x h + f_y k.
  • Maclaurin in two variables — expansion about the origin, a = b = 0.
  • Euler operator — h∂x + k∂y; raised to the power r it generates the order-r group.
  • Exact termination — for a polynomial f the series is finite and the expansion reproduces f identically.

Exam checklist

  • ☐ Did I state the theorem and define h = x − a, k = y − b?
  • ☐ Is there a partials table with every value at (a, b)?
  • ☐ Did the mixed term get coefficient 2 inside the bracket, becoming f_xy hk after the 2! cancels?
  • ☐ Did I count total order (1, 2, 3, 4) for the lines I wrote?
  • ☐ Did I substitute back so the answer is in x and y, or in explicitly defined (x − a) and (y − b)?
  • ☐ Did I check h = k = 0 returns f(a, b)?
  • ☐ For a polynomial f, did I stop at the true degree instead of adding h³, k³ terms?
  • ☐ Did I box the expansion and add one line about when the approximation is valid?

Numeral shortcut

Fastest route through any two-variable Taylor question 1. Write h = x − a, k = y − b immediately.
2. Build the partials table at (a, b): f, f_x, f_y, f_xx, f_xy, f_yy.
3. Read the structure: function of x + y → every monomial appears;
    function of xy → only (xy)^n terms appear.
4. Assemble: f(a,b) → + f_x h + f_y k → + 1/2 f_xx h² + f_xy hk + 1/2 f_yy k².
5. Substitute h, k back into x, y.
6. Check: put h = k = 0, you must get f(a, b).

Find the tangent-plane estimate of f = sin(x + y) at the point (π/6, π/6) for the point (π/4, π/3), and comment

Compute f(π/6, π/6) = sin(π/3) = √3/2, fx = fy = cos(π/3) = 1/2, then apply the first-order line with h = π/12 and k = π/6 to obtain √3/2 + π/24 + π/12 = 1.2587. Then compute the exact value sin(105°) = 0.9659 and compare. The comment is the scored part: the first-order expansion is local, the steps are not small, and the estimate overshoots by 0.2928, so the second-order group would be required for accuracy at that distance.

write — partials at the centre (1) → first-order line (1) → substitute h and k and box the estimate (1) → exact value and error (1) → locality comment (1).
check — the estimate EXCEEDS the true value, so writing that the approximation "underestimates" is wrong; the error figure 0.2928 is what makes the comment credible.
Topper answer format
  1. Statement: Give the theorem and define the shifts h = x − a, k = y − b before any derivative.
  2. Visual: Put a partials table on the page — that table is the working, and the examiner reads it first.
  3. Reason: Assemble one total-order group per line, counting 1, 2, 3 terms, with the 2 in the mixed coefficient shown explicitly.
  4. Close: Substitute the shifts back, box the expansion, and add one line on when the truncation is valid.

Model opening: "Let f(x, y) possess partial derivatives of all orders up to n in a neighbourhood of (a, b), and put h = x − a, k = y − b. By Taylor's theorem for two variables, f(x, y) is the sum of the total-order groups, the r-th being 1/r! times (h∂/∂x + k∂/∂y)r f, evaluated at (a, b)."

For this topic: theorem + shifts → partials table → order 0, 1, 2 lines → substitute back → boxed expansion → one accuracy or total-order comment.

How topper writes answer
  • Shifts first — write h = x − a and k = y − b on the first line; it is a mark and it shortens everything after
  • Partials table before prose — the examiner awards from the table
  • Count total order — 1, 2, 3 terms; it is the fastest way to spot a missing or extra term
  • Underline keywords — total order, Schwarz, tangent plane, Maclaurin, remainder
  • Box the expansion — the full expression in powers of (x − a) and (y − b)
  • Attempt order: polynomial f (terminates, exact) → f(x + y) → f(xy) → estimation questions last
  • Never leave blank: statement + partials table is 40% of any question and both are recall
  • Close every answer: "Hence proved" / the boxed expansion / one validity line

Expand f(x, y) = x² + xy + y² in powers of (x − 1) and (y − 1) up to second order terms

A quadratic function has a finite Taylor series, so the second-order expansion reproduces it exactly — that is the check to aim for.

  h = x - 1 ,  k = y - 1   so  x = 1 + h ,  y = 1 + k
  ==========================================================
   PARTIALS AT THE CENTRE (1, 1)
  ----------------------------------------------------------
        f     = x^2 + x y + y^2        f(1,1)     =  3
        f_x   = 2x + y                 f_x(1,1)   =  3
        f_y   = x + 2y                 f_y(1,1)   =  3
        f_xx  = 2                      f_xx(1,1)  =  2
        f_xy  = 1                      f_xy(1,1)  =  1
        f_yy  = 2                      f_yy(1,1)  =  2
  ----------------------------------------------------------
   ASSEMBLE, ONE LINE PER TOTAL ORDER
  ----------------------------------------------------------
   ORDER 0    1 term    3
   ORDER 1    2 terms   3h + 3k
   ORDER 2    3 terms   1/2 (2)h^2 + 1/2(2)(1) h k + 1/2 (2) k^2
                          = h^2 + h k + k^2
                               |
                               |  hmm: the bracket is
                               |  1/2 [ f_xx h^2 + 2 f_xy hk + f_yy k^2 ]
                               |  = 1/2 [ 2h^2 + 2 h k + 2 k^2 ]
                               |  = h^2 + hk + k^2        CORRECT
                               v
        f = 3 + 3h + 3k + h^2 + hk + k^2
  ----------------------------------------------------------
   SUBSTITUTE BACK:  x = 1 + h ,  y = 1 + k
        3 + 3(x-1) + 3(y-1) + (x-1)^2 + (x-1)(y-1) + (y-1)^2
      = 3 + 3x - 3 + 3y - 3
           + x^2 - 2x + 1 + x y - x - y + 1 + y^2 - 2y + 1
      = x^2 + x y + y^2
        x terms: 3x - 2x - x = 0        constants: 0
        y terms: 3y - y - 2y = 0        -> EXACT
  ==========================================================
   CHECK  h = k = 0  gives  f(1,1) = 3  as required.
   No h^3 or k^3 term: f is quadratic, so f_xxx = 0
   and the series TERMINATES rather than being truncated.
  ==========================================================
  1. Shifts: h = x − 1, k = y − 1, so x = 1 + h and y = 1 + k.
  2. Order 0: f(1, 1) = 1 + 1 + 1 = 3.
  3. Order 1: f_x(1,1) = 3 and f_y(1,1) = 3, giving 3h + 3k.
  4. Order 2: ½2! [2h² + 2(1)hk + 2k²] = h² + hk + k². The mixed coefficient is f_xy hk, because the 2 in the bracket cancels the 2!.
  5. Substitute back and confirm: the expansion simplifies to exactly x² + xy + y², with all linear and constant terms cancelling. Setting h = k = 0 returns f(1,1) = 3.

Exam close: box f = 3 + 3(x−1) + 3(y−1) + (x−1)² + (x−1)(y−1) + (y−1)² and write "the series terminates exactly, since f is a polynomial of degree 2."

Model answer · 7 marks

Expand e(xy) about the origin up to terms of total order 2, and explain why no x² or y² term appears

The whole question turns on noticing that x and y appear only as the product xy, so only powers of xy survive.

  e^(xy) :  x and y appear ONLY as the product
  ==========================================================
   f = e^(xy)
        |
        |  expand in powers of the single quantity u = xy
        v
   u = 0
      |
      +---> 1                      total order 0
      |
      +---> u        =  x y         total order 2   <- 1 + xy
      |                                      is all that
      |                                      order <= 2
      |                                      allows
      +---> u^2 / 2!  =  x^2 y^2 / 2     total order 4  REJECTED
      |
      +---> u^3 / 3!  =  x^3 y^3 / 6     total order 6  REJECTED
  ==========================================================
   CONFIRM WITH PARTIALS AT (0, 0)
  ----------------------------------------------------------
        f     = e^(xy)            f(0,0)     =  1
        f_x   = y e^(xy)          f_x(0,0)   =  0   <--  x dies
        f_y   = x e^(xy)          f_y(0,0)   =  0   <--  y dies
        f_xx  = y^2 e^(xy)        f_xx(0,0)  =  0
        f_xy  = (1 + xy) e^(xy)   f_xy(0,0)  =  1
        f_yy  = x^2 e^(xy)        f_yy(0,0)  =  0
  ----------------------------------------------------------
   ASSEMBLE:  f = 1 + 0 + 0 + 1/2(0) + (1) x y + 1/2(0)
                        = 1 + x y                    [BOXED]
  ----------------------------------------------------------
   NUMERICAL CHECK at (0.1, 0.2):  xy = 0.02
        second order   1 + 0.02            = 1.02
        exact  e^0.02 = 1.0202013
        agree to two decimals, as the order demands
  ==========================================================
  1. Structural observation: since e(xy) is a function of the single quantity u = xy, its expansion is a series in powers of u: 1 + xy + (xy)²/2! + (xy)³/3! + …
  2. Partials at the origin: f(0,0) = 1, f_x(0,0) = f_y(0,0) = 0, f_xx(0,0) = f_yy(0,0) = 0, f_xy(0,0) = 1. The three zeros are precisely why the answer has no x² or y² term.
  3. Assemble: f = 1 + (0)x + (0)y + ½(0)x² + (1)xy + ½(0)y² = 1 + xy.
  4. Why the next term is excluded: the next surviving term is (xy)²/2 = x²y²/2, whose total order is 2 + 2 = 4, so it belongs to the fourth-order group, not the second.
  5. Numerical check: at (0.1, 0.2) the second-order value is 1 + 0.02 = 1.02 against the exact e0.02 = 1.0202, confirming agreement to second order.

Exam close: box 1 + xy and write "no x² or y² term occurs, since e(xy) is a function of the product xy alone; the next term x²y²/2 is of total order 4."

Model answer · 5 marks

Find the tangent-plane estimate of f = sin(x + y) at the point (π/6, π/6) for the point (π/4, π/3), and comment

The first-order expansion is the tangent plane, so the estimate is a linearisation of f about the centre and is only trustworthy for small steps.

  f = sin(x + y) ,  centre (pi/6, pi/6)
  ==========================================================
   PARTIALS AT THE CENTRE
  ----------------------------------------------------------
        f(pi/6, pi/6)  = sin(pi/3)  =  0.866025
        f_x            = cos(x + y)
        f_x(pi/6,pi/6) = cos(pi/3)  =  0.5
        f_y            = cos(x + y) = same
        f_y(pi/6,pi/6)                =  0.5
  ----------------------------------------------------------
   FIRST ORDER (the tangent plane)
        f ~ 0.866025 + 0.5 h + 0.5 k
  ----------------------------------------------------------
   STEPS TO THE TARGET POINT
        h = pi/4 - pi/6 = pi/12
        k = pi/3 - pi/6 = pi/6
  ----------------------------------------------------------
   ESTIMATE   0.866025 + 0.5(0.261799) + 0.5(0.523599)
             = 0.866025 + 0.130900 + 0.261799
             = 1.258724                               [BOXED]
  ----------------------------------------------------------
   COMPARE WITH THE EXACT VALUE
        x + y at the target = 7pi/12 = 105 degrees
        sin 105 deg = 0.965926
  ==========================================================
        estimate 1.258724
        exact    0.965926
        -----------------
        error    0.2928      the estimate OVERSHOOTS

   Why: pi/12 and pi/6 are not small steps, so the linear
        approximation is not valid this far from the centre.
        Adding the second-order group would fix it.
  ==========================================================
  1. Partials at the centre: f(π/6, π/6) = sin(π/3) = √3/2 ≈ 0.866025, and f_x = f_y = cos(x + y) so f_x = f_y = cos(π/3) = 1/2.
  2. First-order line: f ≈ √3/2 + ½h + ½k, the tangent plane at the centre.
  3. Steps: h = π/4 − π/6 = π/12 and k = π/3 − π/6 = π/6.
  4. Estimate: √3/2 + π/24 + π/12 = 0.866025 + 0.130900 + 0.261799 = 1.258724.
  5. Comment: the exact value is sin(105°) = 0.965926, so the estimate overshoots by 0.2928. The first-order expansion is a local result, and the steps here are not small, so the second-order group is needed for accuracy at that distance.

Exam close: box f ≈ 1.2587 (first order) and write "the true value is 0.9659; the error 0.2928 shows the first-order expansion is valid only for small h, k."
