Rolle's Theorem — Verify It, Break It, Ace It

You're prepping for RGPV BT102 mid-terms. Rolle's Theorem is a guaranteed 5–7 mark question every session. By the end of this lesson you'll verify it mechanically, spot failure cases in under 30 seconds, and recognize the exact PYQ patterns RGPV repeats.

The theorem — exactly as RGPV expects you to write it

Let f(x) be a real-valued function defined on [a, b]. If all three of these hold:

#ConditionWhat to check
1f is continuous on [a, b] (closed interval)No breaks, jumps, or vertical asymptotes in [a,b]
2f is differentiable on (a, b) (open interval)No sharp corners or cusps in (a,b)
3f(a) = f(b)Endpoints land at the same height

Then there exists at least one point c ∈ (a, b) such that f′(c) = 0.

The one-second intuition If a curve starts and ends at the same height, and is smooth throughout, it must flatten out somewhere in between. That flat spot is where the tangent is horizontal — slope zero.

Exam tip — the marking scheme RGPV awards marks per step: state conditions (1m), check continuity (1m), check differentiability (1m), show f(a)=f(b) (1m), compute f′(x) (1m), solve f′(c)=0 (1m), verify c ∈ (a,b) (1m). Skip a step, lose a mark.

The verification recipe (your exam algorithm)

Every "verify Rolle's theorem for..." question follows this exact six-step recipe. Memorize it like code:

Step 1: Identify [a, b] from the question
Step 2: Confirm f(x) is a polynomial / trig / exp → automatically continuous
Step 3: Confirm f(x) is differentiable (polynomials always are)
Step 4: Compute f(a) and f(b), check they are equal
Step 5: Differentiate f(x) → set f'(c) = 0 → solve for c
Step 6: Check c ∈ (a, b) → "Hence verified"

Example 1 — the classic PYQ (x² − 4x + 3 on [1, 3])

Q: Verify Rolle's theorem for f(x) = x² − 4x + 3 on [1, 3].

StepWork
1[a, b] = [1, 3]
2f(x) is a polynomial → continuous on [1, 3]
3f(x) is a polynomial → differentiable on (1, 3)
4f(1) = 1 − 4 + 3 = 0, f(3) = 9 − 12 + 3 = 0 → f(1) = f(3)
5f'(x) = 2x − 4; 2c − 4 = 0 → c = 2
6c = 2 ∈ (1, 3) → Hence Rolle's theorem is verified.

Example 2 — x² − 1 on [−1, 1]

Q: Verify Rolle's theorem for f(x) = x² − 1 on [−1, 1].

StepWork
1[a, b] = [−1, 1]
2Polynomial → continuous on [−1, 1]
3Polynomial → differentiable on (−1, 1)
4f(−1) = 1 − 1 = 0, f(1) = 1 − 1 = 0 → equal
5f'(x) = 2x; 2c = 0 → c = 0
6c = 0 ∈ (−1, 1) → Verified.

Example 3 — trigonometric (sin x on [0, π])

Q: Verify Rolle's theorem for f(x) = sin x on [0, π].

StepWork
2sin x is continuous everywhere → continuous on [0, π]
3sin x is differentiable everywhere → differentiable on (0, π)
4f(0) = sin 0 = 0, f(π) = sin π = 0 → equal
5f'(x) = cos x; cos c = 0 → c = π/2
6π/2 ∈ (0, π) → Verified.
Pattern to notice RGPV loves sin x on [0, π] and cos x on [−π/2, π/2]. The answer for sin x is always c = π/2. For cos x on [−π/2, π/2], it's c = 0. Memorize these two.

When Rolle's theorem FAILS (high-value MCQ material)

If any of the three conditions fails, the theorem does NOT apply. RGPV MCQs test this by giving you four functions and asking which one satisfies (or does NOT satisfy) Rolle's conditions.

Failure modeExampleWhich condition breaks
Not continuousf(x) = 1/x on [−1, 1]#1: undefined at x=0
Not differentiablef(x) = |x − 2| on [0, 4]#2: cusp at x=2
Endpoints unequalf(x) = x² on [0, 2]#3: f(0)=0, f(2)=4

Cheat-Sheet · BT102 Mathematics-I

Rolle's Theorem — Quick Reference

Print this page. Use it as a 2-minute refresher before practice sprints and the exam.

The statement (write this verbatim in exams)

Let f : [a,b] → ℜ satisfy:

  1. f is continuous on [a, b]
  2. f is differentiable on (a, b)
  3. f(a) = f(b)

Then ∃ c ∈ (a,b) such that f'(c) = 0.

Verification recipe (6 steps, 7 marks)

StepActionMarks
1State the interval [a, b]—
2Argue continuity (polynomial/trig/exp = auto-continuous)1
3Argue differentiability (polynomials = auto-differentiable)1
4Compute f(a) and f(b), show equal1
5Differentiate, set f'(c) = 0, solve for c2
6Verify c ∈ (a, b), write "Hence verified"2

Three failure modes (MCQ gold)

ConditionFails whenClassic trap
ContinuityVA, jump, removable discontinuity in [a,b]1/x on [-1,1]
DifferentiabilityCusp, corner, vertical tangent in (a,b)|x-2| on [0,4]
Equal endpointsf(a) ≠ f(b)x² on [0,2]

f(x)[a, b]c
x² − 4x + 3[1, 3]2
x² − 1[−1, 1]0
x² − 5x + 6[2, 3]5/2

Geometric meaning (for 2-markers & viva)

  • If a smooth curve starts and ends at the same height, it has at least one horizontal tangent somewhere between.
  • The point c is a stationary point (local max, min, or saddle).
  • Rolle's theorem is a special case of Lagrange's MVT where the secant slope is zero.

Viva questions (RGPV favorites)

QuestionOne-line answer
Who is the theorem named after?Michel Rolle (French mathematician, 1652–1719)
Is the converse true?No — f'(c)=0 does NOT imply f(a)=f(b)
Can there be more than one c?Yes — theorem guarantees at least one
Is f(a)=f(b) sufficient alone?No — need continuity AND differentiability too
What does f'(c)=0 mean geometrically?Horizontal tangent at x=c
Relation to LMVT?Rolle's is the special case of LMVT where slope of secant = 0

Exam-day checklist

  • ☐ Did I check all three conditions before concluding?
  • ☐ Did I write c ∈ (a,b) (open interval) not [a,b]?
  • ☐ Is my c actually inside the interval, not at an endpoint?
  • ☐ Did I write "Hence Rolle's theorem is verified" to close?
  • ☐ For failure questions: did I name which condition breaks?
