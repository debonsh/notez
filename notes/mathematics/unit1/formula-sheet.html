01 — Rolle's Theorem

Conditions: continuous [a,b] + differentiable (a,b) + f(a) = f(b)
Result:     f'(c) = 0 for some c ∈ (a, b)
Classic:    x²−4x+3 on [1,3] → c = 2

02 — Lagrange's MVT

Conditions: continuous [a,b] + differentiable (a,b)  [NO f(a)=f(b) needed]
Result:     f'(c) = (f(b)−f(a)) / (b−a)
Classic:    x² on [1,3] → f'(c) = (9−1)/2 = 4 → c = 2

03 — Taylor & Maclaurin

Taylor:    f(x) = f(a) + (x−a)f'(a) + (x−a)²/2! f"(a) + ...
Maclaurin:  f(x) = f(0) + xf'(0) + x²/2! f"(0) + ...   (a = 0)

04 — Maxima / Minima (2 var)

Stationary: fx = 0 AND fy = 0
r = fxx, s = fxy, t = fyy,  D = rt − s²
D > 0, r > 0 → min | D > 0, r < 0 → max
D < 0 → saddle | D = 0 → inconclusive
