Arrays & Functions — Store Many, Reuse Code

Dec-2020 Q4b literal: "What is function? Write a function to exchange values of two variables." Array-max/search + that swap program are the two most-bankable 5-markers in Unit 2 — both verified below.

Array — one name, many boxes (Exp 09 zone)

int marks[5];              // 5 ints: marks[0] … marks[4]  (ZERO-based!)
marks[0] = 78;             // first box
int m[5] = {78, 55, 32, 90, 61};   // declare + init together
int mat[2][3];             // 2D: 2 rows × 3 cols (tables, matrices)

Loop habitfor (i = 0; i < n; i++) — < not <=!

Function — reusable machine (Dec-2020 Q4b zone)

Function = named block doing ONE job: takes input (parameters),
returns output (return), called whenever needed.

Declaration (prototype):  int fact(int n);        // promise, ends with ;
Definition (body):        int fact(int n) { … }   // the actual work
Call:                     int f = fact(5);        // use it → 120
PartExampleNote
Return typeint / float / voidvoid = returns nothing
Parametersfact(int n)Inputs with types
Body + return{ … return f; }return hands value back
ScopeLocal dies at }Globals visible everywhere (use sparingly)

Verified programs (g++ checked — outputs guaranteed)

// A1: array max (Exp 09) — {78,55,32,90,61} → Max=90
int m[5] = {78, 55, 32, 90, 61}, mx = m[0];
for (int i = 1; i < 5; i++) if (m[i] > mx) mx = m[i];
// OUTPUT: Max=90

// A2: linear search — find 32 → Found at index 2
int key = 32, pos = -1;
for (int i = 0; i < 5; i++) if (m[i] == key) { pos = i; break; }
// OUTPUT: Found at index 2  (-1 = absent)

// A3: matrix add (2x2) — C = A + B
int A[2][2] = {{1,2},{3,4}}, B[2][2] = {{5,6},{7,8}}, C[2][2];
for (int r = 0; r < 2; r++)
  for (int c = 0; c < 2; c++) C[r][c] = A[r][c] + B[r][c];
// OUTPUT: 6 8 / 10 12

// F1: SWAP via function (Dec-2020 Q4b — memorize this!)
void swap(int &a, int &b) { int t = a; a = b; b = t; }
// main: x=10, y=20 → swap(x,y) → x=20, y=10
// WHY &? without it, copies swap and originals stay — 1 mark lives here

// F2: factorial function — fact(6) → 720
int fact(int n) { int f = 1; for (int i = 1; i <= n; i++) f *= i; return f; }
Array and function checks: iterate with i = 0; i < n; i++, start a maximum at m[0], return -1 when a search misses, use a reference for swap, and end a prototype with a semicolon.
Swap check: before the call, x = 10 and y = 20; after a reference swap, x = 20 and y = 10. Without &, the function changes only copies, so the original variables stay unchanged.

Array/function traps
  • i <= n on arrays: reads garbage/past-the-end. Arrays demand i < n. #1 array bug.
  • Swap without &: compiles, runs, prints unchanged values — examiner's favourite trap.
  • Uninitialized max: int mx; then compare = garbage. Always mx = m[0].
  • Missing prototype ;: defining function AFTER main without declaring first = compile error.
Special lines for extra marks
  • "An array trades many names for one indexed name: contiguous boxes, zero-based addresses."
  • "A function is a contract: the prototype promises, the definition delivers, the call collects."
  • "Swap without reference is theatre — copies change costume, originals never move."
  • End with input → trace → boxed output, always.
Exam tips
  • Swap program: memorize with & + why-line + before/after output — 5 marks in 6 lines.
  • Array program: always write init + i<n loop + trace + output.
  • Function theory: declare/define/call/return 4-row table for 2-markers.

Model answer · 5–7 marks

Swap-two-variables function

A function is a named reusable block. Parameters receive inputs, the body performs one job, and return sends a result back when needed.

Reference swap: main() calls swap(x, y)
+-------------------------+  +------------------------------------------------+
|          main()         |->|              swap(int &a, int &b)              |
|      x = 10, y = 20     |  |       a and b reference original x and y       |
|     call swap(x, y)     |  |                   t = a = 10                   |
|                         |  |       a = b = 20; original x becomes 20        |
|                         |  |       b = t = 10; original y becomes 10        |
+-------------------------+  +------------------------------------------------+
|      x = 20, y = 10     |<-|      call finishes; no value is returned       |
+-------------------------+  +------------------------------------------------+

& passes original x and y. Without &: copies change; originals stay 10, 20.
  1. Write the function definition: void swap(int &a, int &b).
  2. Use a temporary variable: int t = a; a = b; b = t;.
  3. Call it from main with two real variables and print before/after values.
  4. Explain that & passes references to the originals; by-value parameters would swap only copies.

Exam close: box the before/after result and write the one-line reason for using &.

Model answer · 5 marks

Array-max / search / matrix

An array uses one name, zero-based indices, and a loop bound of i < n.

m = [78, 55, 32, 90, 61]
+------+------+------+------+------+
| 78   | 55   | 32   | 90 * | 61   |
+------+------+------+------+------+
  [0]    [1]    [2]    [3]    [4]
* m[3] = 90 is the current and final maximum

Maximum trace: mx starts at m[0] = 78
  +-----+-----------+-----------------+----------+
  | i   | m[i]      | compare         | mx after |
  +-----+-----------+-----------------+----------+
  | 1   | m[1] = 55 | 55 > 78: false  | 78       |
  +-----+-----------+-----------------+----------+
  | 2   | m[2] = 32 | 32 > 78: false  | 78       |
  +-----+-----------+-----------------+----------+
  | 3   | m[3] = 90 | 90 > 78: true   | 90       |
  +-----+-----------+-----------------+----------+
  | 4   | m[4] = 61 | 61 > 90: false  | 90       |
  +-----+-----------+-----------------+----------+

Search 32
[78]--false-->[55]--false-->[32]--true-->[position = 2; break]

Search 99
[78]--false-->[55]--false-->[32]--false-->[90]--false-->[61]--false-->[position = -1]
  1. Declare the array and state valid indices 0 to n-1.
  2. Initialise the maximum with m[0] and scan from index 1 to n-1.
  3. For search, initialise position to -1 and break on the first match.
  4. For a matrix, use mat[row][column] and nested row/column loops.

Exam close: state i < n beside the code and box the traced result.

Model answer · 2–3 marks

Function anatomy / scope

The prototype promises, the definition delivers, the call collects, and return hands the value back.

Function runtime using fact
+--------------------+  call   +------------------------+  return  +--------------------+
| int f = fact(5);   |-------->| Function fact(5)       |--------->| f becomes 120      |
+--------------------+         +------------------------+          +--------------------+

Local f lives in main. Parameter n lives in fact.
Global x is visible program-wide; use it carefully.
  1. Declaration gives the return type, name, and parameter types; it ends with a semicolon.
  2. Definition contains the statements and either returns a value or is declared void.
  3. Call supplies actual arguments; parameters may be passed by value or reference.
  4. Local variables end at their closing brace; globals remain visible throughout the program.

Exam close: use one running example to show promise → definition → call → return, then state scope.
