Operators, Expressions, Precedence & I/O

Syllabus lists "Operators, Expressions" then "Precedence and Associativity" — Examiners convert these straight into output-tracing shorts. Master the ladder + integer-division trap and these 2 marks are free.

Precedence ladder — memorize top to bottom (THE table)

HIGH → LOW:
1. ()  []                    brackets first, always
2. !  ~  ++  --  (unary)     right-to-left
3. *  /  %                   left-to-right
4. +  -                      left-to-right
5. <  <=  >  >=                left-to-right
6. ==  !=                    left-to-right
7. &&                         left-to-right
8. ||                         left-to-right
9. ?:  =  += ...             right-to-left  ← LOWEST

Associativity = tie-breaker when precedence ties: arithmetic goes left-to-right (10-4-3 = (10-4)-3 = 3), assignment goes right-to-left (a = b = 5 assigns 5 to b, then a).

Expressions + type conversion

Expression = operands + operators producing a value: (a + b) * c - d / e
int/int → int (7/2 = 3); int/float → float (7/2.0 = 3.5)
Implicit: char→int→float→double (widening, automatic)
Explicit (cast): (float)7/2 = 3.5 — USE THIS in averages!

I/O: cin >> and cout << (Exp 08 zone)

#include <iostream>
int marks;  cin >> marks;          // >> extraction: keyboard → variable
cout << "Marks=" << marks;       // << insertion: variable → screen
cin >> a >> b;                    // chained input, space-separated

Verified dry runs (all g++ checked — trace these by hand first)

int a = 10 - 4 - 3;        // (10-4)-3 = 3        [left-to-right]
int b = 2 + 3 * 4;         // 2 + 12 = 14         [* before +]
int c = 7 / 2;             // 3                   [int division!]
float d = 7 / 2;           // 3.0  NOT 3.5        [division done as int first]
float e = (float)7 / 2;    // 3.5                 [cast fixes it]
int f = 5;  f += 3;        // f = 8
int g = (5 > 3) && (2 > 9);  // 1 && 0 = 0
// OUTPUTS: 3 14 3 3 3.5 8 0
Trace rule: resolve brackets first, then apply precedence, then use associativity for equal-level operators. Show every intermediate value; for averages, cast one operand to float so integer division does not discard the fraction.
Worked trace: 10 + 3 * 2 % 4 - 1 becomes 10 + (3 * 2) % 4 - 1, then 10 + 2 - 1, so the result is 11. The intermediate values belong in the written answer.

Solved examples in great depth

Solved A — trace: int x = 10 + 3 * 2 % 4 - 1;

StepWork
Ladder* % same level (left→right), then + -
Pass 13*2 = 6 → 6%4 = 2
Pass 210 + 2 - 1 = 11
Answerx = 11 ✓ (g++ verified)

Solved B — average of 3 ints done RIGHT (Exp 08 classic)

int a=70, b=80, c=90;
float avg = (a + b + c) / 3;      // WRONG → 80.0 by luck? (240/3=80 exact)
float avg2 = (float)(a+b+c) / 3;  // RIGHT → always correct
// with 70,81,90: wrong = 80.0, right = 80.3333 — cast wins

Solved C — what prints? (midsem tracing short)

int i = 5;
cout << i++ << " ";   // prints 5, THEN i becomes 6
cout << ++i;          // i becomes 7 first, prints 7
// OUTPUT: 5 7  (post uses-then-adds, pre adds-then-uses)
// WARNING: never join both in ONE cout line — order undefined!
Operator traps (the big four)
  • 7/2 = 3: int/int truncates. Need 3.5? Write 7/2.0 or (float)7/2.
  • = vs ==`: `if (x = 5)` assigns (always true); `if (x == 5)` compares. #1 C++ bug in exams.
  • && beats ||: a || b && c = a || (b && c). Doubt? parenthesize.
  • i++` vs `++i`: post = use-then-add; pre = add-then-use. In lone statements identical.
Special lines for extra marks
  • "Precedence decides WHO goes first; associativity decides the ORDER among equals."
  • "Integer division truncates toward zero — the cast (float) is the one-character fix."
  • "When in doubt, parenthesize: brackets cost nothing and prevent precedence bugs."
  • End tracing answers with intermediate values + boxed output.
Exam tips
  • Precedence question: rewrite ladder 1–9 first (1 mark), then trace (1 mark).
  • Average/percentage programs: always cast — examiners specifically test /3 vs /3.0.
  • = vs ==: spotting it in error-finding questions = instant 2 marks.
