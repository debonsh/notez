Lesson · BT205 Unit 2 — C++ Basics

Character Set, Tokens, Data Types & Variables

Syllabus names these verbatim — "Character Set, Tokens" is a ready-made 2-marker. Tokens + type table + first-program anatomy = the foundation every later program question assumes.

Character set (the alphabet C++ reads)

Letters:      A-Z, a-z
Digits:       0-9
Special:      + - * / = % & # ! ? ^ ~ | \ ; : ' " , . < > ( ) [ ] { }
Whitespace:   space, tab, newline (separators, mostly ignored)
Escape:       \n (newline)  \t (tab)  \\ (\ char)  \" (quote)

Tokens — 5 smallest units (THE 2-marker, memorize all five)

TokenWhatExamples
KeywordsReserved words (cannot rename)int, float, if, else, for, while, return, class
IdentifiersNames you invent (variables/functions)marks, total, area_of_circle
Constants/literalsFixed values10, 3.14, 'A', "hello"
OperatorsSymbols that act+ - * / % = == << >>
Separators/punctuatorsStructure marks; , ( ) { } [ ] #

Identifier rules (viva + common error-spotting question)

OK:   letters, digits, underscore; must NOT start with digit
      case-sensitive (Marks != marks); no keywords (int = illegal name)
GOOD: total_marks, n1, _temp     BAD: 1st, my-var, float, my var

Data types + sizes (write the table, not prose)

TypeSize*HoldsExample
int4 BWhole numbers ±21 croreint age = 18;
float4 BDecimals, ~7 digitsfloat pi = 3.14f;
double8 BDecimals, ~15 digitsdouble root = 1.41421356;
char1 BSingle character (ASCII)char grade = 'A';
bool1 Btrue / falsebool pass = true;
void—Nothing (no return value)void show();

*Typical g++ sizes; modifiers short/long/signed/unsigned adjust range (unsigned int = 0…429 crore).

Constants (3 kinds, 1 line each)

Integer:  10, -5, 0x1A (hex), 017 (octal)
Floating: 3.14, 2.5e3 (= 2500.0), -0.5
Character/string: 'A' (1 char) vs "A" (string: A + hidden \0)
Diagram — first program anatomy (draw this) 
SOURCE LINE                   ROLE
-----------------------------  ---------------------------------------------
#include <iostream>       header: declares standard input/output
using namespace std;            std names may be used without std::
int main()                      entry point: execution starts here
{                              begins the main function body
    int age = 18;                tokens: keyword + identifier + constant
                                + operator + separator
    cout << age;                insertion operator writes 18
    return 0;                    reports successful completion
}                                ends the main function

Verified first program (compile it, don't just read it)

#include <iostream>
using namespace std;
int main() {
    int age = 18;
    float pi = 3.14f;
    char grade = 'A';
    cout << age << " " << pi << " " << grade;
    return 0;
}
// OUTPUT (g++ verified): 18 3.14 A
Code-reading check: read the program from the header to main(), identify each token, then trace one small input. If compilation fails, inspect the first error line; a missing semicolon is a frequent cause.
Token check: in float total = price * 1.18;, float is a keyword, total and price are identifiers, 1.18 is a constant, = and * are operators, and ; is a separator.

Solved C — choose types: age, pi, grade, pass, phone number

DataType + why
age = 18int — whole, small
pi = 3.14159double — needs >7 digits
grade = 'A'char — single character
pass = truebool — yes/no
phone = 98260...string, NOT int — never do arithmetic on it (+ leading 0 lost)
Code traps
  • 'A'` vs `"A"`: char vs string (+ hidden \0). char c = "A"; fails.
  • Phone/Aadhaar as int: classic blunder — leading zeros vanish, overflow looms. Use string.
  • float pi = 3.14; warning: 3.14 is double by default; 3.14f silences it.
  • Missing ;: error points to the NEXT line — look one line up.
Special lines for extra marks
  • "Tokens are the atoms of code: the compiler reads characters, groups tokens, then enforces grammar."
  • "Type choice is a contract: int promises whole numbers, double promises precision, string promises identity."
  • "Identifiers obey three laws: no leading digit, no keyword, case matters."
  • End type answers with a type table (type/size/use), never prose.

Model answer · 2–3 marks

Five tokens with examples

A token is the smallest meaningful unit recognised by the compiler. Name all five and give one example each.

SOURCE: float total = price * 1.18;

TOKEN       CATEGORY
----------  --------------------
float       keyword
total       identifier
=           operator
price       identifier
*           operator
1.18        constant (floating literal)
;           separator

Source characters -> C++ tokens -> Grammar rules -> Program meaning
  1. Keywords are reserved words; identifiers are programmer-given names.
  2. Constants are fixed values; operators act on operands; separators mark structure.
  3. Conclude that the compiler groups characters into tokens and then checks grammar.

Exam close: a five-row table with one example per row is the complete answer.

Model answer · 3–5 marks

Data types + identifier rules

Choose a type by the value being stored, then check the identifier rules before compiling.

+----------+------------------+----------------------------------------+
| TYPE     | TYPICAL g++ SIZE | USE                                    |
+----------+------------------+----------------------------------------+
| int      | 4 bytes          | whole numbers; default signed          |
| float    | 4 bytes          | 6-7 significant decimal digits         |
| double   | 8 bytes          | 15-17 significant decimal digits       |
| char     | 1 byte           | one character                          |
| bool     | 1 byte           | true or false                          |
| void     | N/A              | functions return no value              |
+----------+------------------+----------------------------------------+

IDENTIFIER RULES
  first character: letter or underscore (_)
  later characters: letters, digits, or underscore (_)
  case-sensitive: Marks != marks
  forbidden: keywords such as int, float, or return
INVALID: 1st | my-var | my var
  1. Use int for whole numbers, double for precision, char for one character, and bool for yes/no.
  2. An identifier cannot begin with a digit, cannot be a keyword, cannot contain a space or hyphen, and is case-sensitive.
  3. A phone number is identity, not arithmetic: store it as string to preserve leading zeroes.

Exam close: box the type choice and state the reason in one sentence.

Model answer · 3 marks

C++ program structure

Explain each line of a small program, then prove the result with its output.

+-----------------------------+------------------------------------------------+
| PROGRAM PART                | ROLE                                           |
+-----------------------------+------------------------------------------------+
| header directive: iostream  | declares standard input/output                 |
| using namespace std;        | std names may be used without std::            |
| int main() {                | entry point: execution starts here             |
|    int age = 18;            | stores 18 in an int variable                   |
| output: age via cout        | stream insertion writes 18 to standard output  |
|    return 0;                | reports successful completion                  |
| }                           | closes the main function                       |
| OUTPUT: 18                  | proves the program executed                    |
+-----------------------------+------------------------------------------------+
  1. Header supplies declarations; namespace exposes names; main() is the entry point.
  2. Inside main, declaration stores a value, cout writes it, and return 0 reports success.
  3. Every declaration and expression statement ends with the required semicolon.

Exam close: show the complete program and the output line so the answer proves execution.
