MS Word, PowerPoint & Excel

Dec-2020 Q2b literal: "What is text formatting? Discuss alignments in MS-Word + advantages of RTF." Add Excel formulas + PPT anatomy and this practical 7-marker is sealed — plus Experiments 04–06 viva.

MS Word — document creation + formatting (the PYQ core)

Word = word processor: create, edit, format, print documents (.docx).
Text formatting = changing appearance WITHOUT changing words:
font, size, bold/italic/underline, color, superscript/subscript.
AlignmentWhat it doesUse
LeftRagged right, straight leftBody text default
CenterCentered linesTitles, headings
RightRagged left, straight rightDates, page nos
JustifyBoth edges straight (spacing stretched)Newspapers, reports, exams

Paragraph extras with examples: line spacing (1.5 for assignments), bullets/numbering (grocery lists, steps), borders+shading (certificate borders), header/footer (college name + page numbers on every page), mail-merge (one offer letter → 100 personalized copies from an Excel name list), spell-check, tables + images.

RTF advantages (write 3, Dec-2020 asked verbatim)

RTF (Rich Text Format) = portable formatted-text format by Microsoft.
1. Cross-platform: opens in Word, WordPad, LibreOffice, phones.
2. Keeps formatting (bold, fonts, colors) unlike plain .txt.
3. Small + readable + virus-safer than .doc macros.

MS PowerPoint — slides that present

PPT = presentation graphics: slides combining text, images,
charts, audio/video + transitions (slide-to-slide) +
animations (object motion) + slide-show (.pptx).
TermMeaning
Slide + layoutOne page; title/content/two-column/picture layouts
Master slideOne design ruling all slides (college logo + fonts once, appears everywhere)
TransitionEffect BETWEEN slides (fade, wipe, push) — e.g. Fade for seminars, Push for energetic pitches
AnimationEffect ON objects inside a slide (title fly-in, chart zoom, bullet-by-bullet Appear)
Slide showFull-screen delivery (F5) with timings + narration

MS Excel — cells that compute

Excel = spreadsheet: rows (1,2,3) × columns (A,B,C).
Cell = intersection, address like B5. Range = block like A1:A10.
Formula starts with = ; functions are ready-made (SUM, AVERAGE, IF).
ItemMeaning + example
Cell / rangeB5 single; A1:A10 ten cells; A:A whole column
Relative vs absoluteA1 shifts on copy; $A$1 locked (F4 toggles). E.g. price column × single GST rate in $E$1: copy down, rate never drifts
=SUM(A1:A5)Total of five cells
=AVERAGE(B1:B10)Mean of ten cells (class average)
=IF(C2>=40,"Pass","Fail")Decision + result-test favorite
=MAX(B1:B10) / =MIN / =COUNTTopper, lowest, how many appeared — the result-analysis trio with AVERAGE
ChartColumn/bar/line/pie from a range — visual answer. Column = compare students; pie = share of Pass/Fail; line = marks trend across tests

Practical B — Excel: 5 students, total + average + pass/fail

StepWork
GivenMarks in B2:B6 (say 78, 55, 32, 90, 61)
TotalC8: =SUM(B2:B6) → 316
AverageC9: =AVERAGE(B2:B6) → 63.2
ResultC2: =IF(B2>=40,"Pass","Fail"), fill down → Pass,Pass,Fail,Pass,Pass

Spreadsheet check: with marks 78, 55, 32, 90, 61 in B2:B6, =SUM(B2:B6) gives 316 and =AVERAGE(B2:B6) gives 63.2. A column chart turns the same range into a visual comparison.

StepWork
Slides1 title + 2 content (Insert → New Slide → layouts)

Practical traps
  • Transition ≠ animation: between slides vs on objects. Swapping = zero.
  • $A$1 vs A1: copy-down totals need $ lock on rate cells; forgetting = drifting answers.
  • RTF ≠ DOCX: RTF keeps basic formatting portably; macros/VBA live only in doc/docm — viva trap.
  • = first: every Excel formula/calculation starts with =; without it text sits dead.
Special lines for extra marks
  • "Text formatting changes appearance without changing content; justification aligns both margins for report-grade finish."
  • "RTF preserves formatting across platforms — portable where .txt is bare and .doc is heavy."
  • "In Excel the cell is the atom (B5), the range the molecule (A1:A10), the formula the reaction (=SUM(...))."
  • End practicals with saved file + visible check (centered/63.2/slide-show ran).
Exam tips

  • Excel: always write cell addresses + exact =FORMULA() + one computed value.
  • PPT: 5 terms (slide/layout/master/transition/animation) minimum.

Model answer · 7 marks

Text formatting + alignments + RTF advantages

Formatting changes appearance without changing words. Alignments position the line; RTF preserves useful formatting across compatible applications.

+--------------------------------------------------------------------+
| document -> body -> paragraphs -> runs -> characters               |
|             |                     |                                |
|             |                     +-- run formatting (rPr)         |
|             |                        font,size,B/I/U,color,sup/sub |
|             +---+-- paragraph formatting (pPr)                     |
|                 |                                                  |
|                 +-- alignment: Left, Center, Right, Justify        |
+---------------------------------+----------------------------------+
                                  v Save As
+---------------------------------+----------------------------------+
| DOCX (.docx)                    | RTF (.rtf)                       |
| Office Open XML ZIP package     | formatted-text stream            |
| Word / OOXML apps               | Word / LibreOffice / ...         |
+---------------------------------+----------------------------------+
  1. Formatting includes font, size, bold, italic, underline, colour, alignment, and super/subscript.
  2. Left is normal body text; centre suits titles; right suits dates and page numbers; justify makes both margins straight.
  3. RTF is cross-platform, keeps formatting unlike plain text, and is lighter and less macro-prone than a full document format.

Exam close: write the definition, the four-alignment table, three RTF advantages, and one visible document check.

Model answer · 5 marks

Excel: cells, references, functions

A cell is one intersection; a range is a block; every formula begins with =.

+--------------------------------------------------------------------+
| A1 Student   B1 Marks    C1 Result       D1 GST      E1 [IN] 0.18  |
| [IN] typed input   [F] formula   [V] calculated value              |
|                                                                    |
| B2:B6 [IN] 78,55,32,90,61   C2:C6 [V] Pass,Pass,Fail,Pass,Pass     |
|                                                                    |
| C2 [F] =IF(B2>=40,"Pass","Fail")                                 |
|    | copy down to C6                                               |
|    +-- C6 [F] =IF(B6>=40,"Pass","Fail")                          |
|                                                                    |
| D2 [F] =B2*$E$1 ---- copy down to D6 ---- D6 [F] =B6*$E$1          |
| B2 becomes B6: relative; $E$1 stays $E$1: absolute                 |
+--------------------------------------------------------------------+
+------------------------ Calculation cells -------------------------+
| C8 [F] =SUM(B2:B6)       [V] 316                                   |
| C9 [F] =AVERAGE(B2:B6)   [V] 63.2                                  |
+--------------------------------------------------------------------+
  1. B5 means column B, row 5; A1:A10 is a range of ten cells.
  2. Relative B2 shifts when copied; absolute $B$2 stays locked.
  3. Use SUM, AVERAGE, and IF with exact cell addresses and a checked value.
  4. Insert a column chart from the marks range and save the workbook as .xlsx.

Exam close: show the formula and its result beside it, then name the saved file and visible check.

Model answer · 3 marks

PowerPoint anatomy

Separate slide design, object motion, and full-screen delivery; these are the terms examiners check.

+----------------------------------------------------------------------------+
| Theme: colors, fonts, effects                                              |
|   |                                                                        |
|   +-- Slide master: design, logo, master placeholders                      |
|        |                                                                   |
|        +-- Layout 1: title slide ----> Slide 1                             |
|        +-- Layout 2: title + content ----> Slide 2                         |
|        +-- Layout 3: two content ----> Slide 3                             |
| Each slide uses one layout; that layout is based on one master.            |
+----------------------------------------------------------------------------+
                                      v F5
+----------------------------------------------------------------------------+
| Full-screen slide show                                                     |
| [Slide 1] -- transition --> [Slide 2] -- transition --> [Slide 3]          |
|   |                                                                        |
|   +-- [image] -- animation --> [motion on that image]                      |
+----------------------------------------------------------------------------+
  1. A slide is one page; a layout arranges title, content, two-column, or picture placeholders.
  2. A master slide applies one consistent design to all slides.
  3. A transition is between slides; an animation is on an object inside one slide; slide show is full-screen delivery with F5.

Exam close: define all five terms and finish with one saved .pptx and one visible slide-show check.
