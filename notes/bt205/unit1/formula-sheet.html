Unit 1 Key-Sheet — Fundamentals & OS

One page per topic. Print this; leave the six lesson files at home.

01 Definition & classification

computer = electronic IPO device + storage (HW device, SW instructions)
IPO: input(key/mouse) → CPU(ALU+CU) → store(RAM/disk) → output(screen/print)
6 traits: speed · accuracy(GIGO) · diligence · versatility · memory · no-IQ
gens: 1 tubes · 2 transistors · 3 IC · 4 VLSI · 5 ULSI+AI
data: analog(continuous) / digital(0-1) / hybrid(ICU, petrol pump)
size: micro(1 user) / mini(dept) / mainframe(bank/railway) / super(PARAM/FLOPS)

02 CPU / bus / instructions

CPU = ALU(computes) + CU(directs) + registers(scratch-pad)
regs: PC-next · IR-now · MAR-addr · MDR-data · ACC · SP · FLAG · R0-Rn
data=2-way(word size) · address=1-way(2^n mem) · control=signals
[opcode=what | operands=on-what]; cycle: FETCH→DECODE→EXECUTE→STORE
2^10=1K · 2^16=64K · 2^20=1M · 2^30=1G · 2^32=4G

03 Memory / storage / I/O

pyramid: registers > cache > RAM > HDD/SSD > tape
RAM volatile work (SRAM fast/DRAM dense) · ROM boot · cache locality L1>L2>L3
HDD magnetic slow · SSD flash fast · optical laser · tape backup
8b=1B · 1024B=1KB · 1024KB=1MB · 1024MB=1GB · 1024GB=1TB
in: key/mouse/scanner/mic/MICR · out: monitor/printer/speaker

04 Software + applications

system=manages machine (OS/translator/utility/driver) · app=user task
compiler whole→object (C) · interpreter line-by-line (Python)
8 domains: eBiz(cart/UPI) · bio(DNA/drug) · health(CT/ICU) · RS-GIS(image/map)
meteo(forecast) · game(engine) · MM(combined) · animation(24-30fps)

05 OS

OS = interface + resource manager + extended machine (kernel core)
6 fn: process(PCB) · memory(alloc) · files(FAT/NTFS) · devices(spool) · security · UI
types: serial → batch → multiprog → time-share → real-time(deadline)
program passive file · process active + PCB · states: ready→run→wait→end

06 Word / PPT / Excel

Word: L C R J (justify=both straight) · RTF portable formatted text
PPT: slide+layout · master · transition=between · animation=on objects · F5 show
Excel: B5 cell · A1:A10 range · = starts calc · $ locks
=SUM() =AVERAGE() =IF(>=40,"Pass","Fail") · Ctrl+E/J · chart Insert→Column
