Lesson · BT205 Unit 1 — Fundamentals

Computer: Definition, Characteristics, Generations & Classification

The word "computer" comes from "compute" — to calculate. RGPV Q1 almost always opens here: define computer, list parts, classify. This one file banks those 7 marks.

Definition (write verbatim)

A computer is an electronic device that takes data and instructions
as input, processes them under program control, and gives
meaningful information as output, with storage for future use.

Hardware = the electronic device. Software = the set of instructions. Data = raw facts. Information = processed, useful data. This 4-word chain (data → process → information) is the examiner's first tick.

Note — GIGO = Garbage In, Garbage Out (used first in the diagram below) The computer never judges or corrects: wrong input (or a wrong program) always gives wrong output, however fast or accurate the machine is. Example: marks typed as 78 → 87 by mistake print a wrong report card, and the computer will not warn you. Exam line: "Accuracy is conditional — correct input plus correct program; hence GIGO." Reuse this in characteristics (accuracy), limitations, and viva.

Worked mini-example (data → information): data = five subject marks [78, 55, 32, 90, 61] typed in; processing = add + divide by the CPU under the report program; information = Total 316, 63.2%, Pass on the printed card. Same data through a wrong formula gives wrong information — GIGO again.

Read the flow: data and instructions enter, the CPU transforms them under program control, memory holds the work, and output devices present useful information. GIGO means a wrong input or program cannot be silently corrected.

Characteristics worth remembering

#CharacteristicMeaning + exam line
1SpeedMIPS/GHz; millions of ops/sec — "fast execution". E.g. 1 lakh bills totalled before a human finishes one.
2AccuracyError-free if input + program correct (GIGO otherwise). E.g. correct formula → 316/63.2 exact every time.
3DiligenceNo fatigue, no boredom — same accuracy on job 1 and job 1,00,000. E.g. checking 10,000 OMR sheets identically.
4VersatilitySame machine does billing, gaming, design, control. E.g. morning Excel, evening BGMI, night code — one laptop.
5Memory / storageStores vast data, recalls exactly. E.g. 5 years of photos recalled pixel-perfect in seconds.
6No IQ / no feelingsOnly follows instructions; cannot decide on its own. E.g. divides by zero and crashes instead of "understanding".

Generations — 5 rows, memorize technology + example

Gen (years)TechnologyExample / note
1st (1940–56)Vacuum tubesENIAC, UNIVAC — huge, hot, machine language
2nd (1956–63)TransistorsSmaller, assembly language, Batch OS born
3rd (1964–71)ICs (integrated circuits)IBM 360 — keyboards/monitors, high-level languages
4th (1971–2010)VLSI microprocessorsPCs, LAN, Internet, GUI
5th (2010–now)ULSI + AI, parallel, mobileLaptops, cloud, AI/ML — current exam answer

Classification I — by data handled (3 types)

TypeWorks onExample
AnalogContinuous physical quantities (temp, pressure, speed)Speedometer, thermometer, analog signals
DigitalDiscrete 0/1 digitsAll modern PCs, phones — what syllabus means by "computer"
HybridBoth — analog input converted to digitalHospital ICU monitors, petrol pumps, weather stations

Classification II — by size/power (4 types, most-asked table)

TypeWho usesExample
MicroOne person (personal)Desktop, laptop, smartphone, tablet
MiniSmall org / department (multi-user)Departmental servers, PDP-11 classic
MainframeLarge org, huge I/O + reliability (bank, railway)IBM z-series — reservation, banking
SupercomputerMax speed (FLOPS), researchPARAM (India), weather, space, nuclear simulation
Size ladder: micro (one user) → mini (department) → mainframe (large organisation) → supercomputer (highest FLOPS). Capacity, speed, cost, and the number of concurrent users rise together; size does not.
One concrete example: bill values enter as data → the ALU adds them while the CU directs the steps → RAM holds the working total and disk stores it → a printed receipt shows the meaningful information, “Total: Rs 600”.

Solved examples in great depth

BT205 Unit-1 "numerals" here are decision + justification answers. Use this 5-line format for full marks:

Given:   quote the keyword in the question
Find:    which class / generation / characteristic
Rule:    one-line rule (e.g. multi-user dept = mini)
Solve:   apply + eliminate 3 wrong options with reasons
Check:   one use-case line (who uses it / why)

Solved A — classify: railway reservation system

CheckBanks + railways = textbook mainframe use — matches

StepWork

AnswerSecond generation — smaller, faster, less heat than vacuum tubes
Numeral traps
  • Hybrid vs digital: anything measuring continuous physical quantity (temp/pressure/speed/fuel) then showing digits = hybrid, not digital.
  • Mini vs mainframe: department server = mini; bank/railway/census = mainframe. Keyword is scale + reliability.
  • Supercomputer keyword: FLOPS, weather, space, PARAM, research — never tick mainframe for these.
  • No-IQ point: when asked "limitations", always write GIGO + no feelings + needs power — 3 words bank 1 mark.
Special lines for extra marks
  • "A computer is an electronic device operating under program control on the IPO cycle: input → process → output with storage."
  • "Diligence distinguishes computers from humans: identical accuracy on the first and the millionth calculation."
  • "Garbage in, garbage out (GIGO): accuracy is conditional on correct input and correct program."
  • End classification answers with a boxed type + one example + one use line.
Exam tips
  • Write definition + IPO diagram FIRST (2 marks) even before classification.
  • Draw the 4-box IPO diagram — labelled diagrams fetch grace marks.
  • For "parts of computer" (Dec-2020 Q1b): write IPO table + 2 examples per row.
  • Underline keywords: transistor → 2nd gen, VLSI → 4th, PARAM → super, ICU → hybrid.

  • Box every final answer — verdict, classification, output

Model answer · 7 marks

Discuss classification of computers with examples

A computer accepts data and instructions, processes them under program control, stores the work, and produces meaningful information. Classification is written by data handled first, then by size and power.

                     +--------------+----------------------+
                  DATA                                 SIZE

  1. By data: analog uses continuous physical quantities; digital uses discrete 0/1 values; hybrid accepts analog input and processes it digitally.
  2. By size: micro serves one user, mini serves a department, mainframe serves a large organisation, and a supercomputer maximises speed and FLOPS.
  3. Examples: speedometer/thermometer (analog), PC/phone (digital), ICU monitor/petrol pump (hybrid), laptop (micro), department server (mini), bank/railway system (mainframe), PARAM/weather simulation (super).

Exam close: box the requested class, underline one example, and end with: “Classification follows the data representation and the scale of work.”
