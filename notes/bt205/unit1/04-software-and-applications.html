Lesson · BT205 Unit 1 — Software

System vs Application Software + 8 Application Domains

Two 7-markers hide here: "system vs application software" and "computer applications in health/education/GIS". Both are list + 2-points-each answers — this file gives the exact lists.

Software definition (verbatim)

Software = set of programs (instructions + data) that tells
hardware what to do. Hardware alone is a dead machine.
System softwareApplication software
Runs/manages the computer itselfDoes the user's end task
OS, translators, utilities, driversWord, Excel, browsers, games, hospital software
Platform others build onBuilt on top of system software
Example: Windows, Linux, compiler, antivirusExample: MS Word, Tally, Photoshop

Eight-domain recall: e-business · bio-informatics · health care · remote sensing and GIS · meteorology · gaming · multimedia · animation. For an application question, choose the domain, give two uses, and close with one benefit.
Classification test: a compiler, antivirus utility, and printer driver manage or protect the machine, so they are system software. A report editor, browser, game, or billing program serves the user’s task, so it is application software.

Numeral traps (concept traps here)
  • Antivirus = system (utility), not application — most-missed classification.
  • Compiler vs interpreter: whole-program+object file = compiler; line-by-line = interpreter.
  • RS vs GIS: sensing = capturing images; GIS = mapping/analysing them. Write the pair, not one.
  • Multimedia vs animation: multimedia = combined media; animation = moving frames. Gaming uses both.
Special lines for extra marks
  • "System software manages the machine; application software serves the user — the former is the platform, the latter the purpose."
  • "Remote sensing captures the earth from space; GIS turns those images into decisions — crops, roads, disasters."
  • "Bio-informatics is biology computed: genomes in databases, drugs designed by simulation."
  • Close domain answers with a benefit line (cost/speed/reach).
Exam tips

  • Domain answers: heading + 2 bullet points + 1 example — 8 domains × 3 lines = complete page.
  • Dec-2020 Q1a taught: always keep a health + education paragraph ready.

System parts

utilities (antivirus/backup) · drivers (printer/graphics)

Compiler vs interpreter

compiler: whole → object file (C) · interpreter: line-by-line (Python)

Model answer · 7 marks

System vs application software

Software is the set of programs and instructions that tells hardware what to do. System software manages the machine; application software serves a user’s task.

+-----------------------------------+
|        APPLICATION SOFTWARE       |-->|          SYSTEM SOFTWARE          |
|         User-facing tasks         |   |   Manages the computing platform  |
|          GENERAL-PURPOSE          |   |          OPERATING SYSTEM         |
|   Office suite, browser, editor   |   | Processes, memory, files, devices |
|          DOMAIN-SPECIFIC          |   |        LANGUAGE TRANSLATORS       |
|     HIS, accounting, DNA tools    |   |  Compiler, interpreter, assembler |
|  APPLICATION DOMAINS: not layers  |   |             UTILITIES             |
|   E-business, health, education   |   |   Antivirus, backup, compression  |
|       Bioinformatics, RS/GIS      |   |           DEVICE DRIVERS          |
|  Meteorology, gaming, multimedia  |   |     Printer, graphics, storage    |
|             Animation             |   |    Controls hardware through OS   |
+-----------------------------------+   +-----------------+-----------------+
                                                          |
                                                          v
                                        +-----------------------------------+
                                        |              HARDWARE             |
                                        |   CPU, RAM, storage, I/O devices  |
                                        +-----------------------------------+
  1. System software includes the OS, language translators, utilities, and device drivers.
  2. Application software includes office packages, browsers, games, accounting tools, and hospital information systems.
  3. Compiler translates the whole program before execution; interpreter translates and executes line by line; a driver lets the OS communicate with hardware.

Exam close: “System software is the platform; application software is the purpose.” Give two examples in each class.
