Lesson · BT201 Unit 1 — Quantum Mechanics

Operators & Born Interpretation — From ψ to Probability

Topic 01 gave every particle a wavelength. Now: how do we compute with it? Answer: replace every observable with an operator that acts on the wavefunction ψ, and read |ψ|² as probability (Born). This is the grammar Schrodinger equation is written in — master it once, Topics 03–04 become easy.

Why operators?

Classically you measure position x, momentum p, energy E directly. Quantum mechanically the particle IS a wave ψ(x,t), so each observable becomes a mathematical operation on ψ. Measuring = applying the operator and reading its eigenvalue.

operator × wavefunction = eigenvalue × wavefunction
Ôψ = o·ψ    (o = value you measure)

The operator table (memorize this)

ObservableClassicalQuantum operator (1D)
Position xxx̂ = x (multiply by x)
Momentum pmvp̂ = −iℏ ∂/∂x
Kinetic energyp²/2mT̂ = −ℏ²/2m · ∂²/∂x²
Total energyEÊ = iℏ ∂/∂t
Hamiltonian Hp²/2m + VĤ = −ℏ²/2m ∇² + V(x)
Where they come from (2-line origin) Free particle: ψ = Aei(kx−ωt) with p = ℏk, E = ℏω. Differentiate: ∂ψ/∂x = ikψ → −iℏ∂ψ/∂x = ℏkψ = pψ. Similarly iℏ∂ψ/∂t = ℏωψ = Eψ. That is why the operators look that way.

Born interpretation (1926) — the meaning of ψ

Statement (verbatim): |ψ(x,t)|² dx = probability of finding the particle between x and x+dx at time t.

probability density:  P(x,t) = |ψ|² = ψ*ψ
normalization:      ∫−∞∞ |ψ|² dx = 1   (particle is SOMEWHERE)

A valid wavefunction must be: finite, continuous, single-valued, and differentiable (with continuous derivative except at infinite walls).

Free-particle wavefunction

No forces, V = 0, fixed momentum p and energy E = p²/2m:

ψ(x,t) = A·ei(kx − ωt)
k = 2π/λ = p/ℏ      (wave number)
ω = 2πν = E/ℏ       (angular frequency)

|ψ|² = |A|² = constant — a pure free particle is equally likely everywhere (hence real particles are wave packets, Topic 05).

Example 1 — normalize over length L

Q: ψ = A·eikx confined to 0 < x < L. Find A.

StepWork
1∫₀ᴸ |ψ|² dx = |A|² ∫₀ᴸ dx = |A|²L = 1
2A = 1/√L (take real positive)
3Normalized: ψ = (1/√L)·eikx

Example 2 — momentum eigenvalue check

Q: Show p̂ψ = pψ for ψ = A·ei(kx−ωt).

StepWork
1p̂ψ = −iℏ ∂/∂x [A·ei(kx−ωt)]
2= −iℏ · (ik) · ψ = ℏk·ψ
3ℏk = p → eigenvalue is the momentum ✓

Example 3 — reject a bad wavefunction (PYQ style)

Q: Is ψ = A·tan(x) on [0, π] acceptable?

StepWork
1tan(x) → ∞ at x = π/2 — not finite
2Also multi-branch outside — fails single-valued + finite
3Rejected. RGPV loves this 2-marker.
  operator → eigenvalue map

  p̂ψ = −iℏ ψ'  →  p = ℏk
  Êψ = iℏ ψ̇   →  E = ℏω
  Ĥψ = Eψ         →  stationary states (Topic 03)

  |ψ|² dx = probability in dx   ∫|ψ|² = 1

Numericals in great depth — normalization without fear

Only ONE numeral pattern here: find A from ∫|ψ|² = 1. Steps never change:

Given:   ψ (with unknown A) + interval [a, b]
Step 1:  |ψ|² = ψ*ψ  (drop e^(ikx): |e^(ikx)|² = 1 — show this line!)
Step 2:  ∫|ψ|²dx = |A|² × (integral of the rest) = 1
Step 3:  solve for A, take positive root
Check:   plug back — integral must equal exactly 1

Solved A — sine wavefunction (exact warm-up for Topic 04)

Q: ψ = A·sin(πx/L) on [0, L]. Normalize.

StepWork (write exactly this)
|ψ|²|ψ|² = A²·sin²(πx/L) (A real, sin real — no conjugate fuss)
Integral∫₀ᴸ sin²(πx/L)dx = L/2 (standard result — quote it, then use it)
NormalizeA²·(L/2) = 1 → A² = 2/L → A = √(2/L)
Answerψ = √(2/L)·sin(πx/L) — this is the Topic-04 ground state ✓

Memorize ∫₀ᴸ sin²(nπx/L)dx = L/2 — it returns in every box/well numeral.

Solved B — probability in a slice (what Born really asks)

Q: Normalized ψ = √(2/L)·sin(πx/L). Probability in [0, L/2]?

StepWork
Set upP = ∫₀^(L/2) (2/L)·sin²(πx/L)dx
Identitysin²θ = (1−cos2θ)/2, so P = (1/L)[x − (L/2π)sin(2πx/L)]₀^(L/2)
Evaluatesin(π) = 0, sin(0) = 0 → P = (1/L)(L/2) = 1/2
MeaningSymmetric ground state — half the probability in each half ✓
Derivation lines examiners reward (copy these)
  • "Operating on the free-particle wavefunction ψ = Aei(kx−ωt) with p̂ = −iℏ∂/∂x yields eigenvalue p = ℏk, identifying momentum with the operator."
  • "|ψ|² is the probability density (Born, 1926); ψ itself carries no direct physical meaning — only its squared modulus is observable."
  • "A uniform |ψ|² for the pure plane wave implies complete position delocalization, necessitating wave-packet superposition for localized particles (Δx·Δp ≥ ℏ/2)."
  • Always write Ôψ = o·ψ first, then substitute — the general line earns a mark before any algebra.
Numeral traps
  • |eikx|² = 1 — students expand it and drown. Write the modulus line immediately.
  • Complex conjugate: |ψ|² = ψ*ψ, not ψ². For real ψ (sin) they coincide — say so.
  • Limits: box = 0→L, free = −∞→∞. Wrong limits = zero marks for setup.
  • A sign: always take positive root; negative is the same state up to phase.
Exam tips — extra marks
  • Draw |ψ|² vs x (one hump for ground state) — 1 free mark in validity questions.
  • State all 4 validity conditions as a numbered list even if only one is violated — step marks.
  • Underline operators, box A. Examiners scan for ∫|ψ|² = 1 — make it unmissable.
  • Link forward: "This normalization recurs in the 1D-box energies (Topic 04)." — shows command of the unit.

Eigenvalue pattern
