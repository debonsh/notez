# notez

RGPV B.Tech first-year study notes — lessons, cheat sheets, worked numerals,
previous-year drills and self-marking MCQs. Plain HTML, no build step, no
trackers, and it keeps working offline once a page has loaded.

## Live

**https://notez-learn.vercel.app**

Mirror: https://debonsh.github.io/notez/

## What's in it

- 5 subjects, 8 units, 40 topic pages, 200 practice MCQs, 6 formula sheets
- Mathematics-I (BT102), Engineering Physics (BT201), Basic Mechanical
  Engineering (BT203), Basic Civil Engineering & Mechanics (BT204), Basic
  Computer Engineering (BT205)
- One self-contained page per topic: **Lesson**, **Cheat-Sheet**, worked
  examples, PYQ drill sets
- Diagrams are ASCII on purpose, so they can be redrawn by hand in an exam

## How to read it

| key | does |
| --- | --- |
| `Ctrl` + `K` | search every topic, unit and sheet |
| `[` | notes index |
| `o` | sections on this page |
| `f` | focus mode |
| `]` | next topic |
| `?` | keyboard shortcuts |

On a phone the same controls sit in a bar along the bottom of the screen.

## Reading tips

1. Read the **Lesson** tab, then flip to **Cheat-Sheet** — that tab is built to
   be the only thing you read the morning of the exam.
2. Answer the MCQs at the bottom of each topic; they mark themselves and
   explain the answer.
3. Tick topics off on a unit hub. Progress is saved in your own browser.

## This repository

This repo holds the built site only — the notes are authored elsewhere and
synced in. Every page is plain HTML with relative links, so the whole thing can
also be cloned and opened straight off a hard drive.

Found a mistake or a better explanation? Open an issue here and it gets folded
into the page.
